# 육성 v7 설계 — 「터치 다마고치」 (2026-09-10, 40차 제안)

레퍼런스: 사용자 녹화 `AXRecorder_20260910_01_1.mp4`(Talking Tom Hero Dash, 56초). 이 문서는 **기존 육성(프린세스 메이커식 주간 스케줄 카드, `Raising/RaisingUI.cs`)을 통째로 걷어내고**, 캐릭터를 손으로 만지며 키우는 다마고치식 허브로 바꾸는 설계다. 코드는 아직 손대지 않았다.

## 0. 한 줄 컨셉

> **"하늘이는 내 폰 안에 산다."** 육성 화면 = 하늘이가 서 있는 무대 하나. 만지면 반응하고, 배고프면 부르고, 잘 돌봐주면 달리기가 세진다. 스케줄표는 없다. 달리기(러닝)가 곧 '외출'이고, 돌아오면 다시 돌봐준다.

## 3. 터치 인터랙션 사전 (다마고치 핵심)

| 입력 | 어디에 | 반응 | 효과 |
|---|---|---|---|
| **탭** | 캐릭터 몸 | 간지럼 — 움찔 + 웃음 SFX + 하트 파티클 1 | 기분 +1 (1초 쿨다운, 연타 5회면 "그만~" 삐침 표정 2초) |
| **탭** | 머리 | 고개 갸웃 + 말풍선 랜덤 한마디(현재 니즈 기준) | 감성 +0 (정보 전달용) |
| **길게 누르기 0.6s+** | 캐릭터 | 쓰다듬기 — 눈 감고 미소, 손가락 따라 머리 기울기 | 기분 +3/초 (최대 +10/회, 하루 3회) |
| **스와이프 좌우** | 캐릭터 | 빙글 돌기(보드 트릭) | 순발력 +1 (하루 5회) |
| **더블탭** | 포디움 | 점프 + "달릴까?" 말풍선 | 러닝 버튼 강조(펄스) |
| **드래그 → 캐릭터에 드롭** | 간식/장난감/비누/베개 아이콘 | 해당 케어 실행(먹기 애니 등) | 케어 효과(§4) |
| **드래그로 끌기** | 캐릭터 | 발끝이 끌려오며 "우와~" → 놓으면 착지 | 없음(재미) |
| **방치 30초** | – | 하품/앉기/폰 보기 등 자발 행동 3종 랜덤 | – |
| **방치 + 니즈 < 30%** | – | 캐릭터가 화면 앞으로 걸어와 말풍선 "배고파…"(게이지 깜빡) | – |

## 4. 니즈 게이지와 기존 스탯 연결

### 4-1. 니즈 4종 (0~100, 실시간)

| 니즈 | 감소 속도(온라인) | 오프라인 | 0%가 되면 |
|---|---|---|---|
| 🍙 배고픔 | −1/2분 | 최대 8시간분만 반영(다마고치 규칙: 하룻밤 자고 와도 죽지 않는다) | 러닝 시작 체력 −30% |
| 🔋 에너지 | −1/3분, 러닝 1회 −25 | 오프라인엔 **회복** +1/3분(자는 걸로 침) | 러닝 버튼 잠김("좀 쉬자") — 재우기로 해제 |
| 😊 기분 | −1/4분, 방치 시 가속 | 최대 8시간분 | 러닝 중 코인 자석 반경 −50% |
| 🫧 청결 | −1/5분, 러닝 1회 −20 | 최대 8시간분 | 매력 성장 정지, 말풍선 "찝찝해" |

### 4-2. 케어 → 스탯 (기존 `PlayerStats` 그대로 사용, 스케줄표만 없어짐)

| 케어 | 조작 | 니즈 | **스탯 성장**(기존 게이트가 보는 값) | 비용 |
|---|---|---|---|---|
| 🍙 먹이기 | 간식 가방에서 드래그(귤·한라봉·오메기떡·전복죽 4종) | 배고픔 +25~40 | **체력 +1~3**(음식별) | 코인 20~80 |
| 🎮 놀기 | 도크 탭 → 미니게임 3종(**30차 `HomeMiniGames` 재사용**: 리듬탭·보드밸런스·귤받기) | 기분 +20 | **순발력 +2**, 감성 +1 | 무료, 하루 3회 |
| 🫧 씻기 | 비누 드래그 → 문지르기(원 그리기 3바퀴) | 청결 +40 | **매력 +2** | 무료 |
| 💤 재우기 | 도크 탭 → 화면 어두워지고 "잘 자" → 실시간 20분 or 광고/하트로 즉시 | 에너지 +60 | **스트레스 −15** | 무료(즉시는 하트 5) |
| 🗣 말 걸기 | 머리 탭 | – | 감성 +0.2, 평판 +0.2(NPC 대사 섞임) | – |
| 🛍 꾸미기 | 우하단 [방] → **HomeUI 방 꾸미기 v2 재사용** | 기분 +5 | 매력 +1(장식마다 1회) | 코인 |

- 한 스탯이 하루에 오를 수 있는 상한: 체력 6 / 순발력 6 / 매력 4 / 스트레스 −30. (다마고치의 "하루 몇 번" 리듬 = 52주 체력 게이트 곡선과 맞춘 값. CH20 게이트 144를 52주 내 달성하려면 주당 체력 +2.2가 필요 → 하루 6 상한이면 여유 있음.)
- **번아웃 규칙 재해석**: 에너지 0%인데 러닝을 강행(하트 소비)하면 스트레스 +20 → 기존 `Burnout(stress > stamina)` 그대로 발동.

## 5. 시간 — 하이브리드 시계

기존은 "주 1턴, 실행 버튼 → 페이즈 4개 소화". 새 안:

- **현실 시간**이 니즈를 움직인다(§4-1). 
- **스토리 시계(주차 1~52)**는 "하루 마감"으로 간다: **재우기 1회 = 하루**, 7일 = 1주. 즉시 재우기(하트)로 빠르게 넘길 수 있고, 안 재우면 시간이 안 간다(플레이어가 시간의 주인 — 방치 벌칙 없음).
- 챕터 마감(`ChapterRecord.weekEnd`)에 닿으면 기존 그대로 **이벤트 컷씬 → 체력 게이트 → 러닝**(`StoryGate`, `GameManager.GateFail` 로직 무변경). 게이트 불통과면 "한 주 더" — 캐릭터가 "조금만 더 키워줘" 말풍선.
- 러닝은 언제든 가능(에너지 ≥ 25). **챕터 마감 전 러닝 = 연습 런**(하트·코인만, K-POP 모드와 동일 규칙 `ArcadeRun`), **마감 러닝 = 스토리 런**(기존 `StartStoryRun`). 하단 큰 버튼 문구가 바뀐다: 「달리기!」 ↔ 「CH 3 송전탑으로!」(핑크→금색).

## 6. 성장 단계(다마고치의 '진화')

19살 하늘이를 아기→어른으로 바꿀 순 없으니 **'러너 랭크' 5단계**로 시각화한다. 랭크 = 체력+순발력+매력 합.

| 랭크 | 합계 | 무대에서 보이는 변화 | 러닝 |
|---|---|---|---|
| 1 새싹 | ~90 | 기본 노란 점퍼, 맨발 보드 | – |
| 2 동네 러너 | 91~150 | 운동화·헤드폰 | 시작 속도 +5% |
| 3 해안 러너 | 151~230 | 러닝복, 보드 데칼(컬렉션 카드) | 코인 +10% |
| 4 제주 스타 | 231~330 | 반짝이 오라, 포디움에 관중 2명 | 피버 +1초 |
| 5 송전탑의 주파수 | 331+ | 노을빛 의상, 무대 배경이 송전탑 뷰 | 하트 +20% |

랭크업 순간: 화면 하얗게 → 새 의상 등장 연출(기존 `SimpleTween.PunchScale` + 포토카드 개봉 연출 재사용) + 포토카드 1장 지급.

## 10. 구현 순서 (회차 단위, 각 회차 컴파일·캡처 확인)

1. **40차** `NeedsClock` + `SaveData v3` + 오프라인 정산 팝업. 기존 육성 화면은 그대로 두고 HUD에 니즈 4개만 먼저 얹어 수치 밸런스 확인.
2. **41차** `PetStage` — 무대·캐릭터·터치 반응 8종·자발 행동. 기존 RaisingUI 위에 덮어씀(스케줄 UI 숨김).
3. **42차** `CareDock` 4종 + 간식 가방 + 미니게임 연결 + 스탯 성장. 여기서 **스케줄 시스템 코드 삭제**.
4. **43차** 하이브리드 시계(재우기=하루), 챕터 마감→컷씬→게이트 연결 확인, 연습 런/스토리 런 버튼.
5. **44차** 러너 랭크·의상·랭크업 연출, 포토카드 지급.
6. **45차** 에셋 교체(Kling 감정 8종·배경·아이콘), 튜토리얼(집사 손가락 3단계: 만져봐 → 먹여봐 → 달려봐), HANDOVER.

리스크: ① 실시간 니즈는 **에디터 테스트가 느리다** → `RunTuning`에 시간 배속(×60) 디버그 키. ② 52주 밸런스가 실시간과 엇갈릴 수 있음 → 하루 상한값(§4-2)을 SO로 빼서 조정. ③ 저장 마이그레이션 — 기존 세이브의 `queuedSchedule`은 버리고 `needs`는 80으로 초기화.

## 11. 결정이 필요한 것 (답 주시면 40차부터 시작)

1. **시간**: 위 하이브리드(재우기 = 하루)로 갈지, 아니면 순수 실시간(현실 1일 = 게임 1주)으로 갈지. 순수 실시간은 다마고치에 가장 가깝지만 20챕터를 끝내는 데 최소 1년이 걸린다.
2. **스탯**: 기존 6스탯(체력·순발력·매력·스트레스·감성·평판)을 유지하고 니즈 4개를 얹을지(위 안), 아니면 니즈 4개만 남기고 스탯을 체력 하나로 줄일지(게이트만 남음, 더 단순).
3. **광고 자리**: 영상처럼 '영상 보고 즉시 재우기/보상' 슬롯을 지금 UI에 넣어 둘지(SDK 없이 하트 소비로 대체), 완전히 뺄지.
