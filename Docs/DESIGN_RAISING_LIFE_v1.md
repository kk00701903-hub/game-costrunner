# 육성 생활 설계 v1 — 식사·잠·옷·텃밭 (2026-09-12, 57차)

「너와 나의 주파수」 육성 모드의 생활(다마고치) 설계. 지금 코드에 들어간 것(✅)과 다음에 넣을 제안(🔜)을 나눠 적는다.

## 1. 한 턴의 구조

- 한 턴 = 한 주 = 행동 3칸. 행동은 **밥 · 놀기 · 알바** 3종(🔜 「잠」을 밥에서 분리해 4종). ✅
- 3칸을 다 쓰거나 「다음 턴」을 누르면 주가 끝난다. 남은 칸은 버려진다(그 주에 밥/잠을 안 한 것으로 계산). ✅
- 주가 끝날 때 **생활 결산**(Survival.WeekTick) → 「일주일이 지났다」 카드 → 다음 턴. ✅
- 챕터 마지막 주면 다음 턴 시작에 이야기(리더) → 대회(러닝). ✅

🔜 **행동 칸에 시간대 이름을 붙이자**: 1칸 「아침」, 2칸 「낮」, 3칸 「밤」. 규칙은 안 바꾸고 이름만 붙여도 「아침엔 밥, 밤엔 잠」이 자연스럽게 읽힌다. 밤 칸에 알바를 넣으면 「야간 알바 — 잠을 못 잔다」로 결산에 표시.

## 2. 식사(밥)

| 항목 | 값 | 상태 |
|---|---|---|
| 재료 | 쌀 1주분 + 반찬 1주분 (주말 결산 때 자동 소비) | ✅ |
| 효과 | 쌀 → 배부름 +35, 반찬 → 배부름 +10 · 컨디션 +5 | ✅ |
| 밥 행동 | 이번 주 「잠 잤음」 표시 + 쌀이 있으면 배부름 +8, 체력 +1, 스트레스 −5 | ✅ |
| 쌀이 없으면 | 배부름 −40, 굶은 주 +1 (4주 연속이면 쓰러짐) | ✅ |
| 반찬이 없으면 | 컨디션 −5 (「반찬 없이 밥만」) | ✅ |
| 구입 | 장보기: 쌀 60G/주분, 반찬 40G/주분, 4주분 묶음 | ✅ |
| 텃밭 | 토마토(반찬 2주분) · 감자(반찬 3주분) · 쌀(벼, 쌀 2주분) · 장미(스트레스 0) — 2~3주 자라고 수확 때 성공 확률 | ✅ |

🔜 **반찬 등급**: 사 온 반찬 = 보통(컨디션 +5), 텃밭 채소 = 신선(컨디션 +8 · 스트레스 −3), 해녀 엄마의 생선(사이드 씬 보상) = 특별(컨디션 +12 · 하트 +1). 결산 카드에 「오늘 반찬: 감자볶음」처럼 이름을 보여 주면 텃밭에 애착이 생긴다.

🔜 **밥 행동에 메뉴 선택**: 밥을 누르면 「쌀밥+반찬 / 라면(반찬 없이, 40G) / 굶기」 3택. 라면은 배부름은 채우지만 컨디션 +0 — 돈 아끼는 선택지.

## 3. 잠(휴식)

| 항목 | 값 | 상태 |
|---|---|---|
| 판정 | 이번 주에 밥/휴식 행동을 한 번이라도 했으면 「잤다」 | ✅ (🔜 「잠」 행동으로 분리) |
| 못 잔 주 | sleepDebt +1. 2주부터 매주 컨디션 −15 · 스트레스 +10 | ✅ |
| 잘 잔 주 | sleepDebt 0 | ✅ |
| 표시 | 생활 알약 「이번 주엔 꼭 자자」, 결산 카드 「잠을 못 잤다」 | ✅ |

🔜 **잠 행동(분리)**: 기운(=100−스트레스) 회복의 주 수단으로 — 잠 1회 = 스트레스 −25, 컨디션 +6. 밥은 배부름·체력, 잠은 기운·컨디션으로 역할을 나누면 3칸 배분이 고민거리가 된다(밥·잠·알바 = 안정 / 밥·놀기·알바 = 성장·기운↓ / 알바·알바·알바 = 돈·붕괴).
🔜 **밤샘 경고**: 3칸을 알바·놀기로만 채우고 「다음 턴」을 누르면 「오늘 밤 안 자? (한 번 더 누르면 밤샘)」 — 지금의 확인 탭을 문구만 바꿔 쓴다.

## 4. 옷

- 옷 한 벌 = 12주(3개월). 매주 −1. 0이 되면 「낡음」: 컨디션 −8/주, 매력 −1/주. ✅
- 새 옷 300G(장보기). ✅
- 🔜 낡은 옷으로 알바를 가면 수입 −20%(「손님이 눈치 준다」), 카페·미용실 알바는 거절.
- 🔜 계절 옷: 여름·겨울 옷 두 벌 체계는 복잡하니 v1에선 한 벌로 둔다.

## 5. 컨디션과 쓰러짐

컨디션(0~100)은 매주 결산에서 한 번 움직인다. ✅

- 배부름 ≥ 60 → +8 / 30~59 → −8 / < 30 → −22
- 반찬 있음 +5, 없음 −5 · 잠 빚 2주↑ −15 · 옷 낡음 −8
- 컨디션 < 30 이면 체력 −3/주(러닝 게이트가 멀어진다)
- **쓰러짐**: 컨디션 0 이 2주 연속, 또는 4주 굶음 → GameOver 화면 → 「병원에서 깨어나기」(돈 절반 · 컨디션 50 · 쌀 1주분 · 이 주에서 계속) / 「처음부터」(새 회차, 컬렉션·기록 유지)

🔜 컨디션이 행동 결과에도 걸리게: 컨디션 < 30 이면 행동 실패율 +20%, ≥ 80 이면 대성공률 +10%. 「몸이 좋아야 뭐든 잘 된다」가 체감된다.

## 6. 돈 흐름(주 단위 밸런스)

| 수입 | 지출 |
|---|---|
| 알바 1회 60~150G(레벨·평판에 따라) | 쌀 60 + 반찬 40 = **100G/주** |
| 미니게임 성공 150 + 주차×5 G(격주) | 옷 300G / 12주 = 25G/주 |
| 대회(러닝) 코인 → 돈 | 씨앗 180~200G(2~3주에 한 번, 성공 시 반찬 2~3주분 = 80~120G 값어치) |

→ 알바를 주 1회 하면 생활비는 겨우 맞고, 2회면 저축·씨앗·옷이 된다. 놀기(성장)와 알바(생계) 사이에서 3칸을 쪼개는 게 이 모드의 핵심 긴장.

## 7. 자동 모드 규칙 ✅

기운 < 30 → 밥 / 돈 < 100 → 알바 / 체력이 게이트 미만이고 기운 ≥ 40 → 밥 / 그 외 놀기·알바 번갈아. 3칸이 끝나면 스스로 「다음 턴」. 🔜 쌀 0 이면 장보기 먼저(돈이 있을 때).

## 8. 화면 ✅

- 육성: 왼쪽 열 「상태창 / 마이룸 / 장보기」 + 생활 알약(쌀·반찬·옷·배부름·컨디션, 위험하면 ⚠), 말풍선은 오른쪽.
- 상태창 아래 「생활」 구역(배부름·컨디션 막대, 쌀·반찬·옷·이번 주 잠).
- 주간 결산 카드(시안): 아이콘 줄 4개 + 배부름(하트)·컨디션(별) + 다음 턴 예고.
- 체력바: 막대 = 체력/200, 흰 눈금 = 러닝 게이트, 글자 「123 · 게이트 36 ✓」.

## 9. 다음에 할 것(제안 순서)

1. 「잠」 행동 분리(4종 행동, 3칸) + 칸 이름 아침/낮/밤
2. 반찬 등급(보통/신선/특별)과 결산 카드의 반찬 이름
3. 컨디션 → 행동 성공률 연동
4. 낡은 옷 → 알바 수입/거절
5. 밥 행동 메뉴 3택(쌀밥/라면/굶기)
