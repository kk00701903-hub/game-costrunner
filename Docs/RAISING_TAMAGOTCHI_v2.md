# 육성 v7 설계 — 「꼬마 집사의 다마고치」 (2026-09-10, v2 · v1 대체)

v1(`RAISING_TAMAGOTCHI_v1.md`)에 사용자 피드백 반영: **플레이어 = 꼬마(집사)**, 키우는 대상 = 여주인공 하늘이. 그러니 다마고치식 '만지고 먹이는' 돌봄에 더해, **"알바 가", "청소해", "연습해"처럼 시키는 것**이 육성의 절반이다. 기존 육성 요소(알바·자기개발·교습·휴식·스토리 카드, 돈·스트레스·평판·감성·말썽, 계절, 랜덤 이벤트, 호감도)는 버리지 않고 이 두 축에 나눠 넣는다.

---

## 0. 한 줄

> **꼬마가 하늘이를 돌본다.** 손으로 하는 건 「해주기」(음식·놀기·재우기·쓰다듬기), 말로 하는 건 「시키기」(알바·청소·연습·심부름·만남). 해주면 기분이 좋아지고, 기분이 좋아야 시킨 걸 군말 없이 한다. 시킨 걸 하면 돈과 능력이 생기고, 능력이 있어야 송전탑까지 달린다.

플레이어가 꼬마라는 걸 화면이 늘 말해야 한다: **화면 왼쪽 아래에 꼬마(집사) 얼굴**이 항상 있고, 모든 지시는 꼬마 말풍선으로 나간다("누나, 오늘 카페 알바 어때?"). 하늘이는 오른쪽/가운데에서 대답한다. 러닝 중 피버 버튼의 꼬마 얼굴과 같은 얼굴(`UI_Face_Butler`).

## 2. 하루의 구조 (기존 주 4페이즈 → 하루 3슬롯)

| | 아침 | 낮 | 저녁 | 밤 |
|---|---|---|---|---|
| 뭘 하나 | 시키기 1 | 시키기 1 | 시키기 1 | **재우기**(해주기) → 다음 날 |
| 해주기 | 언제든(니즈만 있으면) | 〃 | 〃 | 잠들면 못 함 |

- **시키기 = 슬롯 1개 소비.** 하늘이가 마당에서 사라지고, 카드 그림(`Sched_*` 11장 재사용)이 무대에 뜬 뒤 결과가 돌아온다. 실제 대기 시간은 **0초(기본)** — 다마고치의 실시간은 니즈에만 쓰고, 지시는 턴제로 둔다(테스트·밸런스가 훨씬 쉽다). 옵션으로 "실시간 3분 대기 + 하트로 즉시"도 가능하게 설계(§7).
- 7일 = 1주(`SaveData.week`) → 52주·챕터 마감·체력 게이트·이벤트 컷씬은 **전부 기존 그대로**.
- 슬롯을 안 쓰고 재우면 그냥 하루가 간다(쉬는 날 = 스트레스 −10). 기존 `LifeRhythm`(빡빡/보통/여유)은 하루 슬롯 수 4/3/2로 재해석.

|---|---|---|---|
| 💼 **알바 가** | job_orange 귤농장 · job_cafe 해변카페 · job_delivery 스쿠터배달 · job_haenyeo 해녀돕기(여름) · job_market 오일장 · job_salon 미용실 · job_hall 봉사 · job_dangsan 본향당 · job_lighthouse 등대청소 · job_tower_watch 송전탑 순찰 · **밤 알바**(job_sashimi 횟집·job_night_delivery 심야배달, 말썽↑) · 2회차 job_tower_fix·job_dj_assist | 돈 + 스탯, 스트레스↑, 평판/말썽 | 기운 −25, 배고픔 −15, 청결 −20 |

| 🏃 **연습해** | dev_oreum 오름 · dev_skate 보드 · dev_dance 댄스 · dev_radio 라디오 편지(하트) · 러닝머신(30차) · 교습 les_skate/gym/ham/photo/speech/dance/cook/swim(돈) | 스탯 큰 폭, 돈 −(교습) | 기운 −20, 배고픔 −10 |

### 4-1. 말 듣기(순응) 판정 — 이 설계의 핵심 규칙

시키면 하늘이가 **한다 / 투덜대며 한다 / 거부한다**. 
`순응도 = 기분(0~100) × 0.5 + 친밀도(0~100) × 0.3 + (100 − 스트레스) × 0.2 − 카드 난이도(기존 요구치)`

| 순응도 | 반응 | 결과 |
|---|---|---|
| ≥ 60 | "응, 다녀올게!" | 효과 100% |
| 30~59 | "…알았어" (한숨) | 효과 70%, 스트레스 +5 추가 |
| < 30 | "싫어. 나 지금 배고파" | 슬롯 소비 안 함, 친밀도 −1, 꼬마 말풍선이 **거부 이유**를 알려줌(가장 낮은 니즈) → 해주기로 풀고 다시 시킨다 |

이게 다마고치와 스케줄러를 잇는 고리다: **해주기(니즈)를 안 하면 시키기(스탯)가 안 된다.** 기존 번아웃(`stress > stamina`)은 그대로 — 번아웃이면 무조건 거부.

### 4-2. 친밀도(신규, 0~100)

꼬마↔하늘이. 놀아주기·쓰다듬기·음식(+), 거부당함·밤 알바 강요·연속 3일 방치(−). 50/80에서 하늘이 대사 변화("꼬마야" → 이름 부름), 80 이상이면 **하늘이가 먼저 제안**("오늘은 오름 갈까?" = 추천 카드 하이라이트, 스트레스 −50% 보너스). 세이브 `affinity[]`는 NPC용이라 별도 `bond` 필드.

## 6. 하루 흐름 예시 (튜토리얼이 그대로 이 순서)

1. 아침, 배고픔 40%. 하늘이 "배고파…". → **음식 해주기**(귤+계란 → 계란말이) → 기분↑.
2. 꼬마 "누나, 카페 알바 어때?" → 순응 72 → **알바 감**(카드 그림 뜸, 마당 빔) → 돈 +35, 매력 +2, 스트레스 +10, 청결 −20.
3. 낮, 돌아옴. 청결 30%. → **집안일: 빨래**(슬롯 2) → 청결↑, 방 꾸미기 알림.
4. 저녁, 기분 55. → **같이 놀기: 귤받기** → 기분 75, 친밀도 +2. 슬롯 3에 **보드 연습**(순응 68).
5. 밤 → **재우기**(이불 드래그) → 「오늘의 하늘이」 요약 카드(돈·스탯 변화·내일 예보: "내일은 비, 바다 카드 없음") → 다음 날.
6. 7일째 밤 → 주간 결과(기존 주간 결과 화면을 축약) → 챕터 마감 주면 이벤트 컷씬 → 게이트.

## 7. 랜덤 이벤트·계절·2회차

- 기존 `RandomEventTable`의 페이즈 이벤트는 **"다녀온 뒤 이야기"**로 이식: 알바에서 돌아온 하늘이가 말풍선으로 사건을 말하고(예: "손님이 팁을 줬어!" 돈 +20 / "스쿠터 넘어졌어" 체력 −2), 선택지가 있는 건 꼬마 대답 2개로.
- 계절(`SeasonKind`): 카드 해금·보너스 그대로, 마당 배경·의상 바뀜. 겨울엔 배고픔 감소 ×1.3(다마고치식 계절 난이도).
- 2회차(`Playthrough 2`) 카드(`Ng(...)`)는 그대로 해금.
- 실시간 대기 옵션(끄고 시작): 시키기 후 3분 대기, 하트 5로 즉시. 기본은 0초.

2. **41차** `YardStage`: 마당·하늘이·터치 반응·자발 행동·꼬마 말풍선 줄. 기존 스케줄 UI는 숨김.
3. **42차** `CareTabs` 해주기 4장: 요리(냄비 조합)·놀기(미니게임 연결)·재우기(=하루 넘김)·쓰담. 「오늘의 하늘이」.
4. **43차** 시키기 4묶음: `ScheduleTable` 카드 → 1카드 판정, **순응·친밀도**, 거부 흐름, 외출 중 빈 마당, 다녀온 뒤 이야기(랜덤 이벤트 이식). 여기서 스케줄표 코드 삭제.
5. **44차** 주간 마감·챕터 마감·게이트·컷씬 연결 확인, 연습 런/스토리 런 버튼, 러닝 후 니즈 소모.
6. **45차** 러너 랭크·의상, 친밀도 대사 단계, 튜토리얼(§6 순서), 에셋 교체, HANDOVER.

## 11. 결정 필요 (v1의 3개 → 갱신)

1. **시키기 대기 시간**: 기본 0초(턴제)로 가도 되는지, 아니면 다마고치처럼 실시간 몇 분 기다리게 할지(기본 끔 + 옵션으로 제안).
2. **하루 슬롯 수**: 3(아침·낮·저녁)으로 갈지, 기존 4페이즈 유지할지. 3이면 52주 밸런스는 기존 수치 ×1.33로 보정.
3. **거부 규칙 강도**: 순응도 30 미만이면 슬롯을 안 먹고 거부(위 안) vs. 슬롯도 날아감(더 다마고치답게 냉정). 
4. **청결**: 꼬마가 못 씻기니 "목욕하고 와" 지시(무료·하루 1회)로 두는 게 맞는지, 아니면 집안일(빨래·청소)만으로 청결을 관리할지.
