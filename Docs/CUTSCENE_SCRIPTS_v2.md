# 컷씬 1~8 대본 — 오프닝 형식 (v1, 2026-09-13)

「너와 나의 주파수」 스토리 모드 컷씬 8편을 **오프닝(OpeningCinematic)과 같은 형태**로 다시 설계한 대본.

## 0. 오프닝 형식이란 (기준)

오프닝 1:37 의 뼈대를 그대로 쓴다.

| 항목 | 오프닝 | 컷씬 공통 규칙 |
|---|---|---|
| 구성 | 9컷 × 10초 + 타이틀 카드 | **9컷 × 10초 = 90초** + 마무리 카드(챕터 제목, 음악 끝까지 또는 탭 2.2초) |
| 컷 하나 | (클립 mp4, 스틸 png, 대체 배경, 자막 한 줄) | 같음. 클립 `StreamingAssets/Cine/csN_k.mp4` 있으면 재생, 없으면 스틸 `Cut_CSN_k.png` 켄번즈 |
| 자막 | 1인칭 과거형 한 문장, 20~30자 | **하늘의 1인칭 현재형** 한 문장, 20~32자. 오프닝은 「그때」, 컷씬은 「지금」 |
| 음악 | BGM_Opening(M5 돌아온 제주) 한 곡 | 컷씬마다 M 곡 하나(아래 표). 곡이 끝나면 카드도 닫힌다 |
| 탭 | 탭하면 다음 컷 | 같음. 마지막 컷은 탭해도 2.2초 카드 |
| 색 | 75 % 채도 | **채도 곡선**: 컷씬1 65 % → 2 60 % → 3 55 %(겨울) → 4 45 % → 5 35 % → 6 25 % → 7 15 % → 8 10 %(엔딩 트루에서 100 %로 복귀). 색이 남는 건 **하트·꼬마 우비·부표** 뿐 |
| 재생 위치 | 첫 실행 | 육성 화면 **「다음 턴」** → 이야기(컷씬) → 대회. 시네마 메뉴에서 다시 보기 |

파일 이름 규칙: 클립 `cs1_1.mp4`~`cs8_9.mp4`, 스틸 `Cut_CS1_1.png`~, 카드 배경은 마지막 컷 스틸 재사용.
그림은 기존 `Cut_CHnn_*` 수채 화풍(Kling)으로 통일. 9:16, 1080×1920.

컷씬 ↔ 챕터: 1=CH1 · 2=CH2~4 · 3=CH5~7 · 4=CH8~10 · 5=CH11~13 · 6=CH14~15 · 7=CH16~18 · 8=CH19~20(+엔딩 분기).
롱컷(4·7·10·13·15)의 회상은 각 컷씬 안에서 **세피아 4컷**으로 들어간다.

## 디렉터가 바꾼 것
1. **9컷 → 7컷 × 9초(≈65초)**. 모바일 컷씬은 60~70초가 이탈 없이 볼 수 있는 상한. 오프닝만 9컷 × 10초(영상이 있으니 1:37 그대로).
2. **한 편 = 하나의 질문**. 편마다 마지막 컷은 「그래서 지금 달려야 하는 이유」로 끝난다 — 1편 「아직 아무것도 오지 않았다」, 2편 「돌 세 개는 무너지지 않았다」, 4편 「오늘도, 없었다」, 6편 「여기서 기억이 끊긴다」, 7편 「유리에는 하나만 비쳤다」, 8편 「처음으로 혼자 일어나야 했다」.
