# 컷씬 1~8 대본 — 오프닝 형식 (v1, 2026-09-13)

「너와 나의 주파수」 스토리 모드 컷씬 8편을 **오프닝(OpeningCinematic)과 같은 형태**로 다시 설계한 대본.

## 0. 오프닝 형식이란 (기준)

오프닝 1:37 의 뼈대를 그대로 쓴다.

| 항목 | 오프닝 | 컷씬 공통 규칙 |
|---|---|---|
| 구성 | 9컷 × 10초 + 타이틀 카드 | **9컷 × 10초 = 90초** + 마무리 카드(챕터 제목, 음악 끝까지 또는 탭 2.2초) |
| 컷 하나 | (클립 mp4, 스틸 png, 대체 배경, 자막 한 줄) | 같음. 클립 `StreamingAssets/Cine/csN_k.mp4` 있으면 재생, 없으면 스틸 `Cut_CSN_k.png` 켄번즈 |
| 자막 | 1인칭 과거형 한 문장, 20~30자 | **하늘의 1인칭 현재형** 한 문장, 20~32자. 오프닝은 「그때」, 컷씬은 「지금」 |
| 음악 | BGM_Opening(M5 돌아온 제주) 한 곡 | 컷씬마다 M 곡 하나(아래 표). 곡이 끝나면 카드도 닫힌다 |
| 탭 | 탭하면 다음 컷 | 같음. 마지막 컷은 탭해도 2.2초 카드 |
| 색 | 75 % 채도 | **채도 곡선**: 컷씬1 65 % → 2 60 % → 3 55 %(겨울) → 4 45 % → 5 35 % → 6 25 % → 7 15 % → 8 10 %(엔딩 트루에서 100 %로 복귀). 색이 남는 건 **하트·꼬마 우비·부표** 뿐 |
| 재생 위치 | 첫 실행 | 육성 화면 **「다음 턴」** → 이야기(컷씬) → 대회. 시네마 메뉴에서 다시 보기 |

파일 이름 규칙: 클립 `cs1_1.mp4`~`cs8_9.mp4`, 스틸 `Cut_CS1_1.png`~, 카드 배경은 마지막 컷 스틸 재사용.
그림은 기존 `Cut_CHnn_*` 수채 화풍(Kling)으로 통일. 9:16, 1080×1920.

컷씬 ↔ 챕터: 1=CH1 · 2=CH2~4 · 3=CH5~7 · 4=CH8~10 · 5=CH11~13 · 6=CH14~15 · 7=CH16~18 · 8=CH19~20(+엔딩 분기).
롱컷(4·7·10·13·15)의 회상은 각 컷씬 안에서 **세피아 4컷**으로 들어간다.

## 디렉터가 바꾼 것
1. **9컷 → 7컷 × 9초(≈65초)**. 모바일 컷씬은 60~70초가 이탈 없이 볼 수 있는 상한. 오프닝만 9컷 × 10초(영상이 있으니 1:37 그대로).
2. **한 편 = 하나의 질문**. 편마다 마지막 컷은 「그래서 지금 달려야 하는 이유」로 끝난다 — 1편 「아직 아무것도 오지 않았다」, 2편 「돌 세 개는 무너지지 않았다」, 4편 「오늘도, 없었다」, 6편 「여기서 기억이 끊긴다」, 7편 「유리에는 하나만 비쳤다」, 8편 「처음으로 혼자 일어나야 했다」.
3. **오프닝 자막을 새 스토리로**. 옛 「여섯 해 뒤 그가 돌아왔다」 계열은 폐기. 열두 살 첫 만남 → 행복기(구슬·딱지·앞에 서던 애) → 「스무 살 네 생일, 송전탑 밑에서」 → 열아홉의 아침(기억상실) → 달력 한 줄 = 게임의 목표. 마지막 자막이 곧 튜토리얼이다.

1. **이름이 없다** — 주인공 이름은 끝까지 안 나오고 소년은 「그 애/그」뿐, 「도윤」은 2-4 한 번(그림은 회색 소녀). → 오프닝 2컷에서 **「도윤」** 을 바로 부르고, 1-4 에서 꼬마가 지어 준 이름 **「바다」** 를 따옴표로 세우고, 8-4 마지막에 진짜 이름 **「하늘」** 을 쓴다(= 「바다→하늘」 이 기억 회복의 구조). 2-4 그림은 걸어가는 남자 뒷모습(CH16_Close)으로.
2. **주황 우비 꼬마가 회상에 나온다** — 1-1 이 「처음 보는 꼬마」라 해 놓고 13년 전·8년 전 회상(2-6, 5-5, 6-7)에 같은 우비가 서 있어 「그림 돌려쓰기」로 읽힘. → 1-1 에서 「처음 보는」을 빼고, 2-6 에 **「아빠는 주황 우비를 입고 나갔다」** 를 심어 우비 = 아빠의 흔적이라는 **의도된 복선** 으로 바꿈. 6-7 「혼자」 삭제.
3. **설명 없는 숫자·소품** — 4.2(단위 없음), 돌 세 개, 하트 돌 여덟 개, 16장, 열흘, 숨비소리·아방(방언). → **4.2킬로** 로 통일(3-6·6-1·8-1), 돌 세 개·돌 여덟 개 삭제(2-7 「아빠는 돌아오지 않았다」, 8-5 「탑 아래 우유 한 병뿐」= 1-7·6-4 우유 두 병과 연결), 「16장부터」→「어느 날부터」, 열흘은 4-5 「그 뒤 열흘, 그 애는 안 왔다」로 풀고, 숨비소리는 2-3 에서 「물 위로 내쉬는 엄마의 숨」, 「아방」은 표준어로.

그림-자막 불일치 12곳 처리: 오8(밤 그림↔아침) → END_A3(아침 방)·오9 → CS1_2(달력) / 1-3 「창밖의 마을」로 자막 맞춤 / 1-4·1-5 꼬마 있는 그림으로 / 3-5 봄 그림이라 「열두 살 봄」 / 4-1 「부표가 있던 바위」 / 4-6 「뛰어왔다」 그림을 서 있는 소년(CH12_Close)으로, 3-2 는 앉은 소년(CH18_Mid) / 5-1 「길가에 버려진」 / 5-2 **신규 스틸** / 6-2 열두 살 둘(Open_7) / 7-1 「탑 아래」 / 7-6 중립 표현 / 7-7 「둘 중 하나는 여기 없다」로 제목과 연결. 자막은 전부 34자 이하(자막 띠 bestFit 16~27 안에서 두 줄).
