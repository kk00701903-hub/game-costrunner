## 2. 부족한 부분 — 심층

### 2-1. 농사가 "게임의 중심"이 아니다 (가장 큰 차이)
- 9칸·5종·주 단위 성장이라 **매일 밭에 갈 이유가 없다.** 목장이야기는 "오늘 물 줬나?"가 매일 아침 발걸음을 만든다.
- 계절 구분이 없어 **계절이 바뀌는 설렘(새 씨앗 사러 가기)**이 없다.
- 품질(★)·비료·밭 확장이 없어 **점점 잘하게 되는 성장감**이 없다. 수확 실패 확률(30~50%)은 노력 대비 좌절로 느껴질 수 있다.

### 2-2. 동물과 정이 들 장치가 없다
- 목장이야기의 핵심 감정은 "내 소가 나를 알아본다". 우리는 잡아서 넣고, 달걀이 쌓이고, 토끼는 고기가 된다.
- 쓰다듬기·먹이·이름 짓기·애정 하트가 없어 **동물을 돌보는 재미**가 없다.
- 방목장 말은 보기 좋지만 **만질 수 없는 배경**이다.

### 2-3. 하루의 리듬
- 잠 = 한 주라서 하루가 짧고 "내일 또 하자"의 반복 쾌감이 약하다(대신 주 단위 이야기 진행은 빠름).
- 하루 끝에 **오늘 번 돈·수확·잡은 것 정산 화면**이 없어 마무리 보상이 흐리다.

### 2-4. 주민과의 사연
- 호감도 숫자·선물은 있으나 **호감도가 오르면 보는 장면(하트 이벤트)**이 없어 올릴 동기가 약하다.
- 생일·좋아하는/싫어하는 선물 반응 차이·주민 일과(시간마다 다른 곳에 있음)가 없다.

### 2-5. 축제의 "참여"
- 부스·먹거리·옷은 있지만 **내가 뭔가를 내고 겨루는 순간(작물 품평회·낚시 대회·벌레 대회)**이 없다.

### 2-6. 아늑함 vs 위험
- 오늘 테스트 세이브도 HP 1/200 상태였다. 벌레·산적·귀신·바다가 계속 체력을 깎아 **느긋하게 돌아다니는 재미**를 방해할 수 있다(집 근처 안전지대는 203차에 넓힘).

### 2-7. 이미 목장이야기보다 나은 점 (유지)
- 수집 볼륨(도감 5칸·박물관·광산 던전·보스), 액티비티 미니게임 5종, 버스로 시내·관광지, 땅 사서 월세, 도로 깔아 자동 이동 해금, 장소형 컷씬(목장이야기의 "컷씬이 자꾸 끼어든다" 비판을 피함), K-POP 러닝 연동.

## 3. 재미 요소 체크리스트

| 재미 요소 | 상태 | 메모 |
|---|---|---|
| 짧은 손맛(몇 초~1분): 잡기·캐기·낚기·팡 효과 | ✅ 좋음 | 정령 팡, 드롭 흡수, 낚시 릴 |
| 하루 목표(오늘 할 일) | 🟡 | 일일 미션·부탁은 있음. 하루 끝 정산 없음 |
| 주·계절 목표 | ✅ | 이야기 챕터, 축제, 월세, 도구 등급 |
| 성장감(점점 편해지고 넓어짐) | 🟡 | 도구·도로는 있음. 밭·집·동물 성장 없음 |
| 수집욕 | ✅ 강함 | 도감·박물관·가챠 |
| 애착(돌보는 대상) | ❌ | 동물·밭·주민 모두 "관계 장면"이 약함 |
| 발견·놀람 | 🟡 | 희귀 벌레·날씨. 숨은 장소·계절 한정 생물은 더 가능 |
| 표현(꾸미기) | 🟡 | 마당·방. 집 증축·옷 코디 보여 줄 곳 부족 |
| 이야기 몰입 | ✅ | 장소형 컷씬·기억 조각 |
| 편안함(스트레스 없는 시간) | 🟡 | 위험 요소 많음. 안전지대·난이도 선택 고려 |
| 사회적 보상(주민 반응) | 🟡 | 말풍선 대사는 있음. 호감도 이벤트 없음 |
| 다시 켜고 싶은 이유(내일의 궁금증) | 🟡 | 작물·달걀은 있음. "내일 뭐가 달라질까" 장치 추가 여지 |

## 4. 제안 — 우선순위 (모두 허락 후 진행)

**P1 (재미 체감이 가장 큼)**
1. **동물 돌보기**: 닭·토끼·말에 쓰다듬기/먹이 버튼 → 애정 하트(0~5) → 달걀 품질·특별 달걀, 말은 애정 높으면 타고 달리기. (토끼 고기는 171차 요청 그대로 두되, 애정 높은 토끼는 "가족" 표시 선택지 제안)
2. **농사 확장**: 계절별 씨앗(계절당 3~4종, 총 12종+), 밭 3×3 → 구매로 5×5까지, 비료 → 품질 ★, 비 오는 날 자동 물 주기, 실패 확률을 "시들 확률은 물을 빼먹었을 때만"으로.
3. **하루 정산 화면**: 잠들 때 오늘 수확·판매·잡은 것·호감도 변화를 한 장으로.

**P2**
4. **주민 하트 이벤트**: 호감도 25/50/75/100 마다 짧은 장면(장소형 컷씬 방식 재사용), 생일 달력.
5. **축제 대회**: 유채꽃 축제 = 작물 품평회, 여름밤 축제 = 낚시 대회, 감귤 따기 = 수확 속도 대회, 눈꽃 = 벌레(겨울 곤충)·조각 대회. 순위 보상.
6. **송전탑 테마 특수 도구**(도라에몽 도구 자리): 이야기 챕터마다 하나씩 — 예) 날씨를 바꾸는 "바람개비", 어디서든 집으로 돌아오는 "버스 회수권".

**P3**
7. 주민 일과표(아침 가게·낮 바닷가·저녁 집).
8. 위험 난이도 옵션(느긋 모드: 밤 몬스터·물림 끔).
9. 집 증축(방 하나 → 두 개 → 2층), 레시피 수집 도감.

## 5. 참고 — 목장이야기 쪽 비판에서 배울 점
- 컷씬이 농사를 자꾸 끊는다 → 우리는 장소형이라 이미 회피. 하트 이벤트도 같은 방식으로.
- 레시피 사기 전에 재료를 알 수 없다 → 우리 요리도 재료 미리 보기 유지.
- 동물 몰기 조작이 불편 → 동물 돌보기는 버튼 한 번으로.
- 반복·그라인딩이 느리다 → 도구·자동 이동으로 편의 해금 흐름 유지.
