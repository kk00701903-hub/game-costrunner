# 외부 플레이테스트 진행표 — 「너와 나의 주파수」 (215차)

> 목적: **「돈 주고 살 만한가 · 계속하고 싶은가」**를 처음 해 보는 사람 3~5명에게서 확인한다.
> 방식: 설명 없이 폰(APK)을 건네고 **처음 2시간**을 지켜본다. 도와주지 않는다(막히면 그 자리가 곧 결과).

---

## 1. 준비

- 폰: 안드로이드 1대 이상(가능하면 중급기 1대 포함 — 로딩·발열 확인). `Builds/CoastRun.apk` 설치.
- 새 게임으로 시작(세이브 지우기: 앱 데이터 삭제).
- 기록: 화면 녹화 켜기 + 아래 **관찰표**를 진행자가 적는다.
- 테스터에게 할 말은 이것만: 「이 게임 처음부터 편하게 해 보세요. 생각나는 걸 소리 내어 말해 주면 좋아요.」

## 2. 관찰표 (진행자가 적기)

| 시각 | 무엇을 봤나 | 체크 |
|---|---|---|
| 앱 실행 → 메인 화면 | 걸린 시간(초) | |
| 스토리 모드 → 마을 | **걸린 시간(초)** — 30초 넘으면 표시 | |
| 송전탑 기상 | 「탑에서 내려가기」를 바로 찾았나 | |
| 오프닝 컷씬 | 건너뛰었나 / 끝까지 봤나 / 표정 | |
| 꼬마 따라가기 1·2·3 | 어디서 헤맸나(시간) | |
| 첫 씨 뿌리기 | 무엇을 심었나 · 수확까지 했나 | |
| 자동 이동 | 스스로 발견했나 · 잠긴 곳을 눌렀을 때 반응 | |
| 첫 낚시 | 성공/실패 횟수 · 「!」 타이밍이 짧다고 했나 | |
| 첫 잠(하루 끝) | 하루 기록 화면을 읽었나 | |
| 꼬마와의 약속 | 약속을 알아챘나 · 지키려고 했나 | |
| 러너(K-POP) | 해 봤나 · 몇 판 | |
| 그만둔 시점 | 몇 분에 · 왜(말한 그대로) | |

**「멈칫」 기록**: 5초 넘게 아무것도 안 누르거나, 같은 곳을 세 번 넘게 누르면 시각과 화면을 적는다.

## 3. 끝나고 묻기 (그대로 읽기 · 유도 금지)

1. 이 게임을 한 문장으로 설명하면?
2. 제일 재미있었던 순간은? 제일 답답했던 순간은?
3. 다음에 뭘 하고 싶었나? (다음 목표가 보였는지)
4. 내일 또 켤 것 같나? (1 전혀 ~ 5 꼭)
5. 이 게임이 **유료라면 얼마까지** 낼 수 있나? (0원 / 3,000 / 6,000 / 9,900 / 15,000 이상)
6. 무료에 「이야기 앨범 9,900원」이 있다면 살까? 왜?
7. 비슷하다고 느낀 게임은?
8. 이야기(컷씬)는 어땠나? 마을 부분과 이어진다고 느꼈나?
9. 글씨·버튼이 작거나 읽기 힘든 곳이 있었나?
10. 친구에게 추천한다면 어떤 친구에게?

## 4. 판단 기준 (5명 기준)

| 지표 | 좋음 | 걱정 |
|---|---|---|
| 마을 진입 시간 | 기기에서 15초 이하 | 30초 이상 |
| 첫 30분 안에 그만둔 사람 | 0~1명 | 2명 이상 |
| 「내일 또 켠다」 4~5점 | 3명 이상 | 1명 이하 |
| 유료 의향 6,000원 이상 | 3명 이상 → 선결제 검토 | 1명 이하 → 무료 + 앨범 유지 |
| 앨범 9,900원 산다 | 2명 이상 | 0명 |
| 멈칫 지점 | 사람마다 다름 | **같은 곳에서 3명 이상** → 1순위로 고침 |

## 5. 결과 정리 양식

- 테스터 n명(나이대·평소 하는 게임)
- 평균 플레이 시간 / 그만둔 시점 분포
- 멈칫 지점 상위 3곳(화면·인원)
- 유료 의향 분포 · 앨범 구매 의향
- 인용 3개(좋았던 말 1 · 답답했던 말 2)
- → 다음 차수에 고칠 것 우선순위
