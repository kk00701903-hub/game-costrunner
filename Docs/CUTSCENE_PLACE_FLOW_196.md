# 196차 — 컷씬 장소 흐름 (송전탑 기상 → 꼬마 튜토리얼 → 장소 컷씬 → 엔딩)

## 1. 흐름 한눈에
1. **새 게임**: 오프닝 영상 대신 **송전탑 꼭대기에서 깨어남**(인게임 연출 3컷: 아래서 올려다본 탑 위 → 등 뒤로 마을·바다 → 옆에서 아득한 발밑, 「……?」). 버튼 「⬇ 탑에서 내려가기」.
2. 탑 아래로 내려오면 **담요 자리(돌 세 개)** 가 금빛으로 빛난다 → 걸어 들어가면 **CS1 「모르는 얼굴」**.
3. CS1 뒤 **꼬마 등장 → 튜토리얼 3단계**(꼬마가 앞장서서 걷는다, 빛나는 초록 고리): ① 마을 가게 ② 텃밭 ③ 언덕 위 빈집(🧭 자동이동 안내, 침대 = 한 주).
4. 이후 **챕터(주차)는 그대로 흐르고**, 챕터에 닿으면 그 장(章)의 장면 장소가 빛난다(바닥 금빛 고리 + 빛기둥 + 미니맵 금별 + 지도 라벨 + 상단 「✨ 이야기 「제목」 · 장소」 줄).
5. **꼬마가 그쪽으로 앞장**선다(5 m 넘게 떨어지면). 꼬마에게 말 걸기 → 「🧭 데려다줘」 자동이동.
6. 장소에 들어가면 컷씬 → (EV면 선택 beat) → 단서 카드 → 다음 장면 예고 한 줄.
7. **안 본 장면이 있으면 잠을 못 잔다** — 침대에서 꼬마가 붙잡고 「🧭 데려다줘」.
8. 오프닝 「그 약속」 5컷은 **기억 조각 3개**(파랑 고리, 잠은 안 막음)로 나눠 줍는다.
9. CS8(20장, 송전탑 아래) → 기존 20장 경계 → 엔딩(END_A/B/TRUE, 단서로 분기 — 기존 그대로).

## 3. 허락이 필요한 자막 충돌(바꾸지 않았음)
- **CS1 1컷** 「눈을 떴다. 낡은 담요 위였다.」 — 이제 탑 **꼭대기**에서 깨어나 내려온 뒤 담요 자리에서 CS1이 나온다. 그대로 두면 「깨어남」이 두 번 나온다.
  - 제안 A: 1컷 → 「눈을 떴다. 탑 아래, 낡은 담요 위였다.」(1컷만 수정)
  - 제안 B: CS1을 2컷(「머리 위로 녹슨 쇠기둥이…」)부터 시작
  - 제안 C: 그대로 두기(인게임 기상은 꿈결처럼, 컷씬이 진짜 기상)
- CS1 21컷 「해가 지기 전에 탑 아래 담요 자리에 닿았다」 — 담요 자리를 탑 아래에 두어 맞춤(수정 없음).
