## 0. 결론

- **지금 상태로 ₩50,000 선결제는 권하지 않는다.** 이유는 세 가지다.
  1. **스토어에 올릴 수 없는 상태**: APK 832 MB · 디버그 서명 · AAB 아님(§2-A).
  2. **가격대가 안 맞다**: 모바일 대표 농장 게임 스타듀 밸리가 **₩7,700**(앱스토어 KR), ₩5만 원대는 목장이야기 신작 같은 **콘솔 패키지 가격**(₩64,800)이다. 1인 제작·모바일·AI 생성 에셋 게임이 이 가격대에서 경쟁하려면 분량·마감이 콘솔 수준이어야 한다.
  3. **마감이 덜 됐다**: 보스가 화면 밖, NPC 말풍선 잘림, 가챠 결과에 그림 없음, 낚시·던전 연출 빈약 등(§2-B).
- **좋은 소식**: 안정성은 좋다. 테스트 내내 **콘솔 에러·예외 0**, UI 글자 넘침 0/97, 화면 밖 UI 0, 마을 로딩 3.3초(에디터). 컷씬 그림·음악은 여전히 가장 강한 무기.
- **현실적인 길**(§3): ① 모바일은 ₩5,900~9,900 선결제 또는 지금의 무료+앨범 ₩9,900. ② 5만 원을 원하면 **PC(Steam)·콘솔 완전판**으로 가고, 분량 20시간 이상 + 아래 체크리스트를 채운 뒤.
