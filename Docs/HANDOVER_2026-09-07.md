## 3. 새 채팅에서 이어갈 때 — 절차

### 3-1. Firefly 웹 (영상 생성)
- **Claude 앱 내장 브라우저**에 Adobe ID로 로그인돼 있음(프로필 유지). `preview_start`로 `https://firefly.adobe.com/generate/video` 열면 바로 사용 가능.
- 로그인이 풀렸으면: 그 페이지에서 JS `window.adobeIMS.signIn({redirect_uri: location.href})` 실행 → Sign in 화면 → **사용자가 Adobe ID 이메일+비밀번호로 직접 로그인**(Google 로그인은 QR 휴대폰 인증에 막힘). `auth.services.adobe.com` 사이트 접근은 허용돼 있음.
- 사용자 Chrome은 읽기 전용, Chrome 확장은 미연결 — 조작 불가.
- 설정: 모델 Veo 3.1 Fast(기본), **가로세로비율 → 세로(9:16)**, 재생 시간 8초 또는 10초, 프레임 → 첫 번째 = 해당 `Cut_Open_N.png`. 프롬프트는 `Tools/KlingGen/make_opening_memory.py`의 `SHOTS` vid_prompt 참고.
- 첫 프레임 업로드: 네이티브 파일 선택창은 못 쓰므로 JS로 `HTMLInputElement.prototype.click`을 가로채 input을 잡은 뒤, GitHub raw(`raw.githubusercontent.com/kk00701903-hub/game-costrunner/main/...`, CORS 허용)에서 fetch한 blob을 `DataTransfer`로 `input.files`에 넣고 change 이벤트. 프롬프트는 textarea(shadow DOM)에 native setter로 주입.
- 다운로드: 「다운로드」 버튼은 느리거나 안 됨 → 페이지의 `<video>`(shadow DOM, blob URL)를 fetch해 `<a download>` 클릭. 파일은 `~/Downloads/<uuid>.tmp`로 떨어짐(내용은 정상 mp4). `~/Downloads` 폴더 접근 권한 요청 후 device_bash에서 ffmpeg로 처리.
