# 스토리 모드 분석 · 동물의 숲 포켓캠프 비교 · 개발 보완점 리포트

작성 2026-09-19 · **160차 반영 개정판** · 대상: 「너와 나의 주파수」(Coast Run) 스토리 모드(05_Raising 마을 허브 + 주차 육성)

---

## 0. 한 줄 결론

> 마을을 걷고, 채집하고, 집에서 자는 **뼈대**는 156~160차로 포켓캠프 수준에 닿았다. 160차에서 **「하루 = 활동 4개(밥·놀기·알바·미션) = 1주」** 라는 시간 단위가 확정되고 **일일 미션**이 들어가면서 "오늘 뭘 하지"가 생겼다.
> 아직 없는 것은 포켓캠프의 나머지 두 기둥 — **주민이 나에게 부탁하고 우정이 쌓이는 루프**, 그리고 **모은 재료로 무언가를 만들어 내 공간을 꾸미는 루프**다. 이 둘을 얹으면 스토리(20챕터)와 마을 생활이 서로를 끌어주고, 그때 「5만원짜리」 밀도가 나온다.

**우선순위 Top 5** (160차 이후)
1. 주민 요청(퀘스트) 보드 + 우정 레벨 — NPC 6명을 살아 움직이게
2. 크래프팅(장작·돌·조개·꽃 → 가구·도구) + 제작 시간(자면 완성)
3. 도감(물고기·벌레·조개·작물) + 등대 전시실 기증
4. 미션 3개 선택권 + 주간 스트레치 골, 리젠을 하루 단위로
5. 시간대·계절 생물 + 낚시/벌레 대회(랭킹) — 밤에 나갈 이유

## 4. 보완 과제 (구체안 · 난이도 · 효과)

> **시간 단위 결정(160차, 확정)** — 「하루 = 활동 4개(밥 · 놀기 · 알바 · **일일 미션**) = 1주」.
> 잠들면 한 주가 지나간다. 축제(6·14·21·42주)·챕터 주차·주간 결산을 그대로 쓰면서 마을 쪽은 「하루」로 말한다.
> 아래 과제는 모두 이 단위를 전제로 다시 정리했다. (구 버전의 "주 단위 vs 하루 단위" 미결 항목은 해소됨)

### ✅ D. 일일 미션 — **160차 구현 완료**
- 아침마다 미션 1개가 정해진다(주차 시드 → 같은 날 다시 들어와도 같은 미션): 벌레 2마리 · 나무 패기 · 돌 캐기 · 텃밭 돌보기 · 낚시 · 3개 줍기 · 마을 사람 2명과 대화.
- 목표를 채우면 **하루 네 번째 활동**으로 세고 돈 35~45G + 별조각 2 + 경험치. HUD 오른쪽 띠에 「🎯 … (1/2)」, 마을 메뉴에 「🎯 오늘 미션」(무엇을·어디서·보상).
- 남은 과제: 미션 **3개 동시 제시**(포켓캠프식 선택권) → 아래 D2.

### D2. 미션 3개 + 주간 스트레치 골  ★★★★ (난이도 하)
- 아침에 3개를 깔고 그중 **아무거나 하나**를 네 번째 활동으로 인정(나머지는 보너스 보상만). 선택권이 생기면 "오늘은 이게 귀찮다"가 사라진다.
- 주간(=챕터) 스트레치 골 6칸: 「장작 20」「미션 5회」「우정 Lv 합 5」… → 큰 보상. 기존 `AchievementTable` 형식 재활용.

### A. 주민 요청(퀘스트) + 우정 레벨  ★★★★★ (효과 최상 · 난이도 중) — **다음 1순위**
- NPC 6명이 각자 **하루 1개 요청**(잠자면 갱신): 「토마토 2개」「조개 3개」「장작 5개」. 성격대로 종류를 나눈다(해녀 할머니 = 조개·물고기, 꽃집 언니 = 꽃·씨앗, 낚시 소년 = 벌레·물고기, 카페 알바 = 요리·재료, 등대지기 = 장작·돌, 서퍼 = 조개·별조각).
- 일일 미션과의 관계: **미션 = 하루 한 칸(활동)**, **주민 요청 = 칸을 쓰지 않는 자유 활동**(가방에서 건네주기만). 둘이 겹치지 않게 역할을 나눈다.
- 보상: 돈 + 우정 EXP. 우정 Lv1→5: 새 대사 3줄 · Lv2 포토카드 · Lv3 가구 레시피 · Lv4 일상 장면(DailyScenes 재활용) · Lv5 **단서 1개**(엔딩 분기 → 스토리와 마을이 묶인다).
- 데이터: `SaveData.villageQuests[6]`(npc·item·n·done·week), `npcFriend[6]`. 미니맵에 요청 NPC 마커.

### B. 크래프팅 워크벤치  ★★★★★ (난이도 중)
- 우리집 책상 → 「만들기」: 장작·돌·조개·꽃·작물 + **잠 1~3번**(= 1~3주) → 마당 가구, 도구 업그레이드(잠자리채 반경↑, 도끼 2타), 보존식.
- 잠 몽타주에서 「🔨 벤치 완성!」로 회수 → 자는 행위에 기대감이 붙는다(160차의 하루=1주 단위와 정확히 맞물림).
- 기존 `RoomDeco`·마당 `YardDef(price)` 에 `recipe` 추가. **지금 장작은 연료 8주분이 끝이고 돌·조개는 쓸 곳이 없다** — 소비처 확보가 핵심.

### C. 생물 도감 + 등대 전시실  ★★★★ (난이도 하~중)
- 물고기·벌레(3→8종)·조개·버섯·작물을 `Collection` 「생물」 탭으로. 처음 잡으면 「NEW!」 카드.
- 등대지기 집을 전시실로: 기증 → 모형이 늘고 20종·40종에 보상. 일일 미션(잡기 계열)과 도감이 서로를 끌어준다.

### E. 시간대·계절 생물 + 채집 대회  ★★★ (난이도 중)
- 밤 전용 벌레(반딧불이·사슴벌레), 새벽 물고기 → **밤에 나갈 이유**(귀신 위험과 맞바꾸는 우리만의 긴장감). 활동 4개를 다 쓰고도 밤에 나갈 동기가 된다.
- 축제 주 앞뒤로 낚시·벌레 대회(3분, `ContestRivals` 점수 → 등수 보상).

### F. 리액션 · 사진 모드  ★★★ (난이도 하)
- 대화 길게 누르면 이모트 6개(하트·웃음·놀람·화남·잠·박수), NPC가 응답하면 우정 EXP 소량.
- 사진 버튼: HUD 숨김 + 카메라 회전/줌 + 포즈 3종 → `NativeShareLite` 공유.

### G. 옷·외형  ★★★ (난이도 중)
- `LifeItemCat.Clothes` 를 소모품에서 **외형**으로: 상의 색·모자·가방 3~4종(SkaterRig 머티리얼 교체). 우정·크래프팅 보상으로 획득.

### H. 마을 공용 공간 꾸미기  ★★ (난이도 중)
- 정자 광장·해변을 꾸미기 구역으로. 배치한 가구에 우정 Lv 높은 NPC가 찾아온다(포켓캠프 「캠프장 초대」).

### I. 리젠 리듬 — **하루(=잠 1회) 기준으로 재조정**  ★★★ (난이도 하)
- 나무 8주 → **2주**, 돌 8주 → **3주**, 줍기(가지·조개·버섯)는 주 1회 → **잠자면 리젠**(하루 1회), 텃밭 물 주기도 페이즈 단위 → **하루 1회**로 통일.
- 지금은 하루에 할 수 있는 채집이 금방 바닥나서 "미션 말고 할 게 없다"가 된다.

### J. 온보딩 · UI  ★★★ (난이도 하)
- 첫 마을 진입 시 하루 루프 가이드 4단계(식탁 → 알바나라 → 정자 → 침대) + 미니맵 마커.
- HUD 활동 표시(「활동 1/4 밥놀알미」)를 **아이콘 4칸 게이지**로. 미션 띠와 나란히.
- ✅ 조이스틱: 160차에 **탕탕특공대식 플로팅 조이스틱**(아래 화면 아무 데나 눌러 생성, 손가락 따라 링 이동, 떼면 사라짐)으로 교체 완료.

### K. 비주얼 잔여  ★★ (난이도 하~중)

- **시간 단위(해결)**: 「하루 = 활동 4개 = 1주, 잠들면 주 경과」로 확정(160차). 스토리의 주차·축제·결산은 그대로 두고 마을 텍스트만 「하루」로 말한다. 앞으로 추가하는 요청·리젠·제작 시간은 모두 **잠 횟수**를 단위로 쓴다(예: 제작 2주 = 두 번 자기).

- **성능**: 마을이 프리미티브 수천 개(집·기와·꽃) — 저사양 기기에서 드로우콜 부담. 정적 배칭/메시 합치기(VillageFlora 처럼) 한 라운드 필요. 드롭·반짝이 오브젝트도 풀링.
