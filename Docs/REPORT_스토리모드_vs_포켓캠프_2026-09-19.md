# 스토리 모드 분석 · 동물의 숲 포켓캠프 비교 · 개발 보완점 리포트

작성 2026-09-19 (159차 기준) · 대상: 「너와 나의 주파수」(Coast Run) 스토리 모드(05_Raising 마을 허브 + 주차 육성)

## 0. 한 줄 결론

> 마을을 걷고, 채집하고, 집에서 자는 **겉모습(뼈대)** 은 156~159차로 포켓캠프 수준에 가까워졌다. 하지만 포켓캠프가 사람을 매일 돌아오게 하는 **"주민이 나에게 부탁한다 → 재료를 모아 준다 → 우정이 오르고 새 것이 열린다"** 루프와 **"재료로 무언가를 만들어 내 공간을 꾸민다"** 루프가 없다. 이 두 루프를 얹으면 스토리(20챕터)와 마을 생활이 서로를 끌어주는 구조가 되고, 그때 「5만원짜리」 콘텐츠 밀도가 나온다.

**우선순위 Top 5**
1. 주민 요청(퀘스트) 보드 + 우정 레벨 — NPC 6명이 살아 움직이게
2. 크래프팅(장작·돌·조개·꽃 → 가구·도구·장식) + 제작 시간(잠자면 완성)
3. 도감(물고기·벌레·조개·작물) + 기증/전시(박물관 or 등대 전시실)
4. 일일 목표 3개 + 주간 스트레치 골(체크리스트 보상)
5. 시간대·계절별 생물 + 낚시/벌레 대회(랭킹) — 밤에 나가는 이유 만들기

## 4. 보완 과제 (구체안 · 난이도 · 효과)

### A. 주민 요청 보드 + 우정 레벨  ★★★★★ (효과 최상 · 난이도 중)
- 마을 NPC 6명 각자 **하루 1개 요청**(잠자면 갱신): 「토마토 2개」「조개 3개」「생선구이 1개」「나비 1마리」「장작 5개」. 요청 종류는 NPC 성격대로(해녀 할머니 = 조개·물고기, 꽃집 언니 = 꽃·씨앗, 낚시 소년 = 벌레·물고기, 카페 알바 = 요리·재료, 등대지기 = 장작·돌, 서퍼 = 조개·별조각).
- 보상: 돈 + 별조각 + **우정 EXP**. 우정 Lv1→5: 새 대사 3줄씩, Lv2 사진(포토카드), Lv3 가구 레시피, Lv4 일상 장면(DailyScenes 재활용), Lv5 「단서」 1개(엔딩 분기와 연결 → 스토리와 마을이 묶임).
- UI: 말하기 버튼 → NPC 말풍선에 요청 카드(필요 아이템·수량·보상), 마을 메뉴에 「📋 오늘의 부탁」 목록, 미니맵에 NPC 마커.
- 데이터: `SaveData.villageQuests[6]`(npc, item, n, done, day), `npcFriend[6]`. 요청 생성은 시드(주차·NPC)로 결정적.

### B. 크래프팅 워크벤치  ★★★★★ (효과 최상 · 난이도 중)
- 우리집 책상(또는 마당 작업대) → 「만들기」: 장작·돌·조개·꽃·작물 + 시간(1~3주 = 잠 1~3번) → 마당 가구(벤치·화분·가로등·울타리·우편함 색), 도구 업그레이드(잠자리채 Lv2 = 잡기 반경↑, 도끼 Lv2 = 2타에 쓰러짐), 요리 재료 가공(보존식).
- 기존 `RoomDeco`·마당 `YardDef`(price)에 `recipe` 필드 추가 → 돈 또는 재료로 획득. 만들기 중인 것은 침대 몽타주 때 「🔨 벤치 완성!」.
- 이유가 생긴 채집: 지금 장작은 연료 8주면 끝, 돌·조개는 쓸 곳이 없음 → 소비처 확보.

### C. 생물 도감 + 기증  ★★★★ (난이도 하~중)
- 물고기(FishingMini 어종)·벌레 3종→8종·조개·버섯·작물을 `Collection`에 「생물」 탭으로. 처음 잡으면 「NEW!」 카드.
- 등대(등대지기 집)를 전시실로: 기증하면 전시장에 모형이 늘어나고, 20종·40종에 보상(별조각·가구 레시피). 포켓캠프의 박물관+카탈로그 역할.

### D. 일일 목표 · 주간 스트레치 골  ★★★★ (난이도 하)
- 아침(잠 깬 뒤) 3개: 「벌레 2마리」「알바 1회」「텃밭 물 주기」 등 무작위. 다 하면 별조각 +5. 주간(챕터) 스트레치 골 6칸: 「장작 20」「우정 Lv 합 5」… → 큰 보상.
- HUD 알약 옆 「🎯 2/3」 배지, 마을 메뉴에 체크리스트. 기존 `AchievementTable` 데이터 형식 재활용.

### E. 시간대·계절별 생물 + 채집 대회  ★★★ (난이도 중)
- 밤 전용 벌레(반딧불이·사슴벌레), 새벽 전용 물고기 → **밤에 나갈 이유**(귀신 위험과 트레이드오프 = 우리만의 긴장감).
- 축제 주(6·14·21·42) 앞뒤로 「낚시 대회」「벌레잡기 대회」: 제한 시간 3분 마을 채집, `ContestRivals` 라이벌 점수와 랭킹 → 등수 보상. 기존 축제 미니게임(ChapterMissionUI)을 마을 채집으로 대체·추가.

### F. 리액션 · 사진 모드  ★★★ (난이도 하)
- 대화 버튼 길게 → 이모트 6개(하트·웃음·놀람·화남·잠·박수). NPC 근처면 NPC도 응답(우정 EXP 소량).
- 사진 버튼: HUD 숨김 + 카메라 회전/줌 + 캐릭터 포즈 3종 → `NativeShareLite` 공유. 「5만원 게임」 인증샷 채널.

### G. 옷·외형 반영  ★★★ (난이도 중)
- `LifeItemCat.Clothes` 를 소모품에서 **외형 아이템**으로: 상의 색·모자·가방 3~4종 SkaterRig 머티리얼 교체. 우정 보상·크래프팅 결과물로 획득. 얼굴 데칼처럼 머리 액세서리 데칼 추가 가능.

### H. 마을 공용 공간 꾸미기  ★★ (난이도 중)
- 정자 광장(28,-6)과 해변 앞을 「마을 꾸미기」 구역으로: 크래프팅 가구를 마을에도 배치, 배치한 가구에 NPC가 앉거나 모임(우정 Lv 높은 NPC가 찾아옴 = 포켓캠프 「캠프장 초대」).

### I. 리젠 리듬 조정  ★★ (난이도 하)
- 나무·돌 8주는 너무 김(주 1회 채집 게임 리듬) → 나무 2주·돌 3주, 줍기(가지·조개·버섯)는 **잠자면 리젠**(주 1회 → 하루 1회). 텃밭도 하루 단위 물 주기(현재 페이즈 단위) — 하루 = 잠 1회 기준으로 통일.

### J. 온보딩 · UI  ★★★ (난이도 하)
- 첫 마을 진입 시 「하루 루프」 가이드 4단계(집 식탁 → 알바나라 → 정자 놀기 → 침대), 각 단계 미니맵 마커 + 화살표. 기존 `RaisingTutorial` 형식.
- HUD 알약 텍스트(「11주차 봄 · Lv.11 · 활동 1/4 밥놀알·」)를 아이콘 4칸 게이지로, 미니맵에 오늘 요청 NPC·미완 활동 마커.
- 문 앞 프롬프트에 「A 버튼」 힌트 통일, 결과 말풍선은 탭 없이 3초 자동 닫힘 옵션.

### K. 비주얼 잔여  ★★ (난이도 하~중)
- NPC 6명 외형 차별화(모자·색·소품, 해녀 할머니 잠수복·꽃집 앞치마…), NPC 걷기 루트(집↔일터) → 마을이 「사는」 느낌.
- 지붕 기와 텍스처(클링, UV 필요), 창문 밤 불빛, 바다 반사, 계절 잎 색(SeasonPalettes 재활용) — 157차 리포트와 동일.

### L. 스토리 ↔ 마을 연결  ★★★★ (난이도 하)
- 챕터 컷씬에 나온 장소·인물을 마을에서 만나게: 컷씬 뒤 「등대에 가 보자」 같은 **마을 목표**를 주고 도착하면 EV 보조 컷씬·단서. 지금은 이야기는 화면에서, 생활은 마을에서 따로 논다.

## 6. 리스크 · 주의

- **시간 단위 충돌**: 스토리는 「주차」, 마을은 「하루(잠)」. 현재 잠 1회 = 1주로 묶었는데 요청·리젠을 "하루"로 설계하면 사실상 주 단위가 됨. 축제·챕터 주차를 건드리지 않으려면 **잠 = 1주 유지**하고 텍스트만 「하루」로 통일하거나, 「한 주 안에 7일 × 4활동」으로 바꾸는 큰 결정을 해야 함(후자는 결산·축제 재설계).
- **세이브 호환**: 요청·우정·레시피·도감 필드 추가 시 기존 세이브 기본값 처리(`LifeItems.Ensure` 방식).
- **성능**: 마을이 프리미티브 수천 개(집·기와·꽃) — 저사양 기기에서 드로우콜 부담. 정적 배칭/메시 합치기(VillageFlora 처럼) 한 라운드 필요. 드롭·반짝이 오브젝트도 풀링.
- **클링 크레딧**: 텍스처·아이콘 추가는 잔여 크레딧(≈57) 안에서 우선순위 정할 것(지붕 기와·NPC 얼굴·도감 아이콘).
- **5만원 가격 정당화**: 포켓캠프는 무료라 비교 대상은 「스타듀밸리(약 8천원~1.5만원)·동물의 숲 NH(6만원대)」 급. 이야기 20챕터 + 위 루프 + 마을 꾸미기 + 도감이 모두 있어야 "완결형 유료 게임"으로 설득 가능. 데모(1~3챕터) 무료 + 정식 구매 구조 권장.
