## 2. 차수별 기록

### 173차 — 경계 바위 띠
- 사용자 시안(둥글둥글한 파스텔 바위가 쌓인 담)에 맞춰 Firefly 로 `Tex_RockBand.png`(파스텔 자갈밭) 생성.
- `VillageWorld.BuildBoundaryDeco`: 경계선(z=45.3, x=±45.3)마다 바위 무더기(`BoulderCluster`)를 깔고, 소나무는 네 칸에 한 번만 뒤로.
- 캡처 비교 3회로 크기·색을 조정(첫 시도는 달걀만 하게 컸고, 두 번째는 자갈 모자이크처럼 잘게 박혔다).

### 174차 — 바위 전면 재작업 · 잔디 · 카메라
- **바위**: 옛 껍데기(블렌더 키트 `VStone_A/B`, `VRock_A/B/C`, 칙칙한 회색 구)를 전부 걷어내고 `VillageWorld.PastelBoulder()` 하나로 통일.
  - 경계 담·언덕·길가·**캘 수 있는 광석 바위**까지 같은 덩이. 광석 결정만 남겨 캘 수 있는 것임을 알아보게 했다.
  - 재질: Firefly 로 만든 매끈한 돌 표면 `Tex_RockSurf.png` + 파스텔 6색 틴트(`BoulderTint`).
  - **콜라이더 복구** — 173차에 내가 지워 놔서 바위를 그냥 통과했다. 지금은 막힌다.
- **잔디**: Firefly 잔디 타일 `Tex_GrassTile.png` 생성 → ① 스플랫 색에 38% 섞고 ② 툰 셰이더 디테일 맵 **R 채널을 이 잔디로 교체**(`Tex_Detail.png` 재작성), 타일 3.3 m · 세기 0.48.
- **카메라(1차)**: 가림 때문에 당기는(확대) 로직을 껐다.

### 174차-2 — 카메라 안정화 (사용자: 「뱅글뱅글 돈다 / 집이 사라진다」)
- 171차 **비켜 돌기**(0.4초마다 ±35/70/105/140° 중 재선택)가 남아 있어서 움직일 때마다 각도를 새로 골라 돌았다 → **껐다**.
- 171차 **낮게 붙기**, 172차 **위에서 내려다보기**도 껐다(주인공 정수리만 크게 잡히던 원인).
- 결과: 카메라는 항상 주인공 뒤 같은 각도·거리. 가리는 것 중
  - 작은 소품(바위·나무·울타리) → 가린 동안만 렌더러 끄기
  - **집·상점처럼 큰 것(경계 6 m 초과) → 텍스처를 살린 반투명(알파 0.30)** (`VillageHub.GhostMat`)
- 관련 코드: `VillageHub.LateUpdate` / `HideThinOccluders` / `RestoreHidden` / `CamFree(solidOnly)`.

### 174차-3 — 울타리 · 현무암 · 바닷가 바위 · 날씨
- **울타리**: Firefly 나무결 `Tex_Wood.png` → `VillageHouses.WoodMat()` 으로 기둥·가로대에 입힘. `LogFence` 를 쓰는 텃밭·농장·방목장 울타리가 전부 바뀐다.
- **현무암 담**: 집 앞으로 길게 뻗던 한 줄을 없애고 **우리집 마당을 두르는 담**으로(가로 ±14.7 m, 세로 26.4~40.8 m). 대문(길) 자리와 송전탑 자리는 건너뛴다.
- **바닷가 바위**: 각진 현무암 키트(`VCliff_A/B`)를 버리고 마을과 같은 둥근 덩이로. 바닷가만 청회색·라벤더·회색(찬 색, `coolMat` 인덱스)만 골라 쓴다.
- **마을 날씨**: `WeatherFx`(러닝에서 쓰던 것)를 마을에 붙였다.
  - 70~140초마다 맑음·흐림·비·눈이 바뀐다. 계절별 확률(겨울 눈 34% / 여름 비 30% / 그 외 비 22%).
  - **비·눈에 돌아다니면 5초마다 체력 1 감소.** 시작 시 토스트, 상태 알약에 「비/눈」 표시, 집 안에선 멈춤.
  - 코드: `VillageHub.WeatherTick` / `PickWeather` / `DevWeather`.

### 175차 — 밤 몬스터 펫 (사용자: 「포켓몬스터처럼」)
- 밤에만, 스폰 판정마다 **5% 확률**로 한 마리. 보랏빛 무리를 두른 펫 그림(`Obs_Pet_*.png` 빌보드)이 1 m 높이에서 둥둥.
- **잠자리채로 잡으면 펫 상점과 같은 취급** — `ownedPetMask` 에 들어가고, 펫이 하나도 없으면 바로 장착. 이미 가진 펫이면 별조각 +3 · 30G.
- 코드: `VillageCreatures` (kind 6, `SpawnMonster`, `Night` 플래그, `OnMonsterCaught`) / `VillageHub` 에서 수령 처리.
- 도망 속도 조정: 처음 2.5 m 안에서 1.9 m/s 로 달아나 못 잡았다 → **1.2 m 안에서 1.1 m/s**.
- **미확인**: 실제 펫 획득 분기. 지금 세이브가 4종을 이미 다 보유해서 「이미 있음」 쪽만 탔다. 펫 없는 세이브로 한 번 확인 필요.

### 176차 — 지붕·벽·구름 · 방목장
- **지붕** `Tex_Roof.png`: 둥근 기와 결. **채도를 크게 낮춰 중성화** — 집마다 지붕색(틴트)이 그대로 먹어야 하기 때문.
- **벽** `Tex_Plank.png`: 가로 판자 사이딩. 역시 중성화.
- **구름** `Cloud_Cumulus_A/B/C.png`: Firefly 2장 생성 + 1장은 A의 변주(좌우 반전·납작하게). 하늘 돔 자체는 **건드리지 않았다**(밤낮 틴트를 쓰는 그라데이션이라 그림으로 갈면 전환이 깨진다).
- **방목장**(신규 `Village/VillageRanch.cs`): 언덕 서쪽 x −39~−23, z 19~41.
  - 통나무 울타리(동쪽 가운데 문) · 빨간 헛간 · 목장집 · 여물통 · 건초 3덩이.
  - **말 4마리**(`RanchHorse`): 어슬렁 0.9 m/s, 35% 확률로 2~4초 달림(3.2 m/s), 다리 흔들기, 멈추면 고개 숙여 풀 뜯기. 울타리 안에서만.
  - 말은 블렌더 대신 **절차 생성**(치비 비율). 1차본이 목만 길어 낙타 같았다 → 몸통을 앞뒤(Z)로 눕히고 목을 짧고 굵게, 주둥이·귀·갈기·꼬리를 다시 붙여 2차본에서 잡았다.

### 177차 — 담 방향 · 헛간
- **현무암 담이 판때기처럼 보이던 원인**: 간격이 아니라 **방향**. `Prop_StoneWall` 은 **길이가 Z 축**인데 앞뒤 담에 yaw 0 을 줘서 조각이 담 진행 방향과 직각으로 서 있었다.
  - 교정: 앞뒤 담 **yaw 90**, 옆 담 **yaw 0**, 간격 1.6 m, 경사 기울기만큼 땅에 묻기(최대 0.85 m).
- **헛간**: 평평한 지붕판 → 박공 지붕(앞뒤 경사면 + 용마루), 방목장 쪽으로 큰 문 + 흰 십자 트림 + 건초 다락 창.

## 3. 이번 세션에서 배운 함정 (다음 세션 필독)

1. **포토샵 MCP 의 생성형 도구는 안 먹는다.** `photoshop_generative_fill` / `photoshop_generate_image` 는 "생성형 채우기 명령을 현재 사용할 수 없습니다" 로 거부된다(ExtendScript `syntheticFill` 도 동일). 계정·크레딧 문제가 아니다.
   - **우회**: 문서를 만들고 `select_all` 한 뒤 **화면의 상황별 작업 표시줄에서 「이미지 생성」을 클릭**해 프롬프트를 타이핑한다(computer-use). 모델은 **Firefly Image 5**(프리미엄) 선택.
   - 상황별 작업 표시줄이 사라지면 `창(W) → 상황별 작업 표시줄` 을 껐다 켠다.
2. **`photoshop_export_as` 는 알파를 날린다**(RGB 로 저장). 투명 PNG 가 필요하면 **배경색 그대로 내보낸 뒤 PIL 로 키잉**해서 RGBA 를 만든다. (구름 A를 이 때문에 불투명하게 덮어썼다가 `git show HEAD:<path>` 로 복구했다.)
3. **`Tex_GrassTile.png` 은 `.meta` 의 `isReadable: 1` 이 필요하다.** 스플랫을 굽는 코드가 `GetPixels32()` 로 읽기 때문. 임포트 후 meta 를 고치고 다시 Refresh.
4. **`Prop_StoneWall` 은 길이가 Z 축.** 담을 x 방향으로 놓으려면 yaw 90.
5. **원격 파일 스테이징 함정**: `device_bash` 로 방금 쓴 파일은 잠깐 `nlink>1` 로 보여 `device_stage_files` 가 거부한다. **10~15초 기다렸다 재시도**하면 된다. `unity_shot` 의 PNG 는 하드링크라 직접 못 올린다 → PIL 로 다른 이름·다른 폴더에 복사본을 만들어 올린다.
6. **텔레그램 보고**: 유니티 없이도 보낼 수 있다. `Tools/Telegram/outbox.txt` 에 쓰고 **포토샵 ExtendScript `app.system('cmd /c python ... send_outbox.py')`** 로 실행하면 된다(Cowork 셸은 api.telegram.org 가 프록시에서 막힌다).
7. **어도비 크레딧**: 프리미엄 4000/4000(2026-10-22 재설정), 표준 기능은 무제한. 포토샵 오른쪽 위 프로필에서 확인(패널은 webview 라 computer-use 허용 목록에 `msedgewebview2.exe` 가 있어야 보인다).
