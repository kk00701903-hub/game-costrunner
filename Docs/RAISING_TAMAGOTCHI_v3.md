# 육성 v7 설계 v3 — 「심플 다마고치 + 자동 육성」 (2026-09-10, v2 대체)

v2에서 사용자 요청으로 **최대한 간소화**: 행동 3개, 게이지 2개, 화면 1장, 그리고 **자동 육성 모드**. 꼬마(플레이어)가 하늘이를 돌본다는 틀은 유지. 게이트·컷씬·러닝·K-POP 모드는 코드 변경 없음.

---

## 0. 한 줄

> **밥 · 놀기 · 알바, 세 버튼.** 세 번 하면 하루가 가고, 일곱 밤이면 한 주. 귀찮으면 「자동」을 켜면 하늘이가 알아서 산다. 플레이어는 보다가 만져주기만 해도 된다.

## 2. 규칙 — 전부 여기 있음

| 행동 | 효과 | 니즈 | 하루 | 비고 |
|---|---|---|---|---|
| 🍳 **밥** | 체력 +2 | 기운 +40 | 3회 | 돈 −15. 요리 종류 선택 없음(계절 요리가 자동으로 나옴: 봄 고사리비빔밥 …). 돈 0이면 "라면"(체력 +1, 무료) |
| 🎮 **놀기** | 순발력 +2, 매력 +1 | 기분 +30, 기운 −10 | 2회 | 미니게임 3종/방 꾸미기 중 랜덤 1개. 미니게임 결과 좋으면 +1 보너스 |
| 💼 **알바** | 돈 +30~60, 체력·매력 중 하나 +1 | 기운 −30, 기분 −10 | 2회 | **카드 선택 없음** — 기존 `ScheduleTable` 알바 중 계절·해금·현재 Lv에 맞는 것 하나를 자동으로 고르고, 돌아와서 한 줄로 말한다("귤 따고 왔어, 40G!"). 밤 알바·말썽·평판 계열은 **삭제** |
| ✋ **만지기** | – | 기분 +2/회(하루 최대 +10) | ∞ | 탭=웃음, 길게=쓰다듬기, 스와이프=보드 한 바퀴 — 다마고치 손맛만 남김 |
| ▶ **달리기** | 러닝 | 기운 −30 | 기운 ≥ 30일 때 | 연습 런 언제든, 챕터 마감 주엔 스토리 런 |

- **하루 = 행동 3번**(어떤 조합이든). 3번째 행동이 끝나면 자동으로 밤 → 「오늘」 한 줄 카드(체력 +4 · 돈 +25) → 아침. 재우기 버튼 없음.
- 밤이 되면 기운 +50 회복(자는 걸로). 기운 0이면 밥·놀기만 가능. 기분 0이면 알바 효과 절반 + 하늘이 뾰로통(거부 없음 — 간소화).
- 7일 = 1주. 52주·챕터 마감·**체력 게이트(24+6×챕터)**·이벤트 컷씬·클로즈 컷씬·K-POP 모드 스탯 적용: 기존 코드 그대로.
- 실시간 감소·오프라인 정산 **없음**. 앱을 꺼도 아무 일도 안 일어난다(간소화 우선; 다마고치 손맛은 터치 반응과 자발 행동으로만).
- 스트레스는 내부적으로 `기분`으로 통합(`stress = 100 − mood`) → 기존 `Burnout(stress > stamina)`은 "기분이 체력보다 낮으면 알바 불가"로 자연스럽게 남는다. 감성·평판·말썽·호감도·2회차 카드·교습·집안일·청결·친밀도·랜덤 이벤트 선택지: **전부 삭제**(NPC 사이드 씬은 컷씬 쪽에서만).

체력 곡선 확인: 하루 밥 3번이면 체력 +6/일 → 주 +42는 과하다. **주당 상한 +12**(게이트 CH20=144까지 52주 기준 주 +2.2 필요 → 여유 5배, 자동 모드가 대충 굴러도 통과). 상한은 `RunTuning`에 두고 조정.

## 3. 자동 육성 모드

HUD 오른쪽 토글 「자동」. 켜면:

1. 하늘이가 **1.2초마다 스스로 행동**(배속 1×/3×/10× 탭으로 순환). 선택 규칙 — 위에서부터 첫 번째:
   - 기운 < 30 → 밥 (돈 없으면 라면)
   - 기분 < 30 → 놀기(미니게임은 자동 플레이 결과 = 보통 등급)
   - 돈 < 100 → 알바
   - 이번 주 체력 상한 남았고 기운 ≥ 40 → 밥
   - 그 외 → 놀기·알바 번갈아
2. 꼬마 말풍선이 진행을 읽어 준다("알바 다녀왔어 +40G", "3일째 저녁"). 무대에선 하늘이가 나갔다 들어오는 짧은 연출(0.4초)만.
3. **플레이어 개입**: 자동 중에도 무대를 만지면 기분 보너스, 행동 버튼을 누르면 그 행동을 끼워 넣는다(자동은 멈추지 않음).
4. **멈추는 조건**: 챕터 마감 주 도착(「CH n 송전탑으로!」 버튼이 펄스하고 자동은 일시정지 → 러닝은 플레이어가), 러너 Lv 상승(랭크업 연출 뒤 계속), 앱 백그라운드.
5. **빠른 진행**: 「자동」 토글을 1.5초 길게 누르면 「챕터 마감까지 돌리기」 — 화면 어두워지고 요약 한 장(주차·돈·Lv 변화)으로 즉시 챕터 마감 주에 도착. 테스트·바쁜 유저용.
6. 자동 모드 결과는 수동보다 **효율 −15%**(알바 최저 카드, 놀기 보통 등급)로 두어 손으로 하는 이유를 남긴다.

세이브: `SaveData.autoRaise(bool), autoSpeed(int)`. 자동 상태는 앱을 껐다 켜도 유지(켜져 있으면 육성 화면 들어오자마자 다시 돈다).

## 7. 결정 필요 (2개만)

1. **알바 카드 선택**: 완전 자동(위 안)으로 갈지, 「알바」를 누르면 **카드 2장 중 하나 고르기**만 남길지(선택의 재미 vs 간소화).
2. **자동 모드 효율 −15%**: 두는 게 맞는지, 손/자동 동일로 갈지.
