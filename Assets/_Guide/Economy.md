## 강화 (5부위 × Lv15)

`UpgradeSystem` + `UpgradeCosts`

| 부위 | 만렙 효과 |
|------|-----------|
| 데크 | 피격 복구 1.5s → 1.0s |
| 트럭 | 레인 0.18s → 0.13s, 버퍼 120→160ms |
| 휠 | 최고속 +1.5, 부스터 4s → 5s |
| 베어링 | 그라인드 붕괴선 회복 +3m, 균형 +35% |
| 그립 | **반격창 +0.3s 상한**, 착지 경직 -40% |

- 한 부위: 코인 **47,200** / 합금 **123**
- 전체: 코인 **236,000** / 합금 **615**
- 전 부위 만렙 성능 향상 **≤ 25%** (`UpgradeSystem.PerformanceCap`)
- 텔레그래프 0.45s · HP 3칸은 강화로 절대 안 건드림
- 트럭·휠: 구역 2·3 클리어 해금. 베어링·그립: 조각 15개씩

검증: `Tools > 347 > Validate Economy Numbers`
