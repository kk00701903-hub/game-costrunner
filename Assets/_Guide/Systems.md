# 『347』 — 시스템과 숫자

> 세계관과 대사는 [Story.md](Story.md) 를 봅니다. 이 문서는 **규칙과 숫자**만 다룹니다.
> 값은 전부 인스펙터에 노출된 실제 필드입니다. 괄호 안은 스크립트 이름입니다.

---

## 1. 플레이어 상태

우선순위는 위가 이깁니다. 충돌하는 입력은 여기서 정리됩니다 ([PlayerController](../Scripts/PlayerController.cs)).

```
DEAD > COUNTER > INVULN > HURT > GRIND > WALLRUN > AIR > SLIDE > RUN
```

| 값 | 숫자 |
|----|------|
| 기본 속도 | `9 m/s` |
| 최고 속도 | `20 m/s` |
| 거리당 가속 | `0.0035 m/s per m` (1600 m 마다 약 +5.6) |
| 점프력 / 중력 | `8` / `-20` |
| 슬라이드 | `0.7초`, 콜라이더 높이 `0.5` |
| 회전 유예 | 코너 중심 통과 후 `3 m` |
| 피격 스턴 | `0.3초` |
| 입력 버퍼 | `0.12초` |
| 코요테 타임 | `0.10초` |

## 2. 데크 HP

3칸입니다 ([PlayerVitals](../Scripts/PlayerVitals.cs)).

| 값 | 숫자 |
|----|------|
| 최대 HP | `3` |
| 무적 시간 | `1.2초` |
| 피격 감속 | 속도 `×0.7`, `1.5초`에 걸쳐 회복 |
| 편지 부활 무적 | `3초` |

- 표시는 숫자가 아니라 **데크 상태**입니다. 3칸=온전, 2칸=금, 1칸=쪼개짐 ([PlayerSpriteView](../Scripts/PlayerSpriteView.cs)). 화면 가장자리 붉은 비네트가 함께 진해집니다
- 숫자 HUD가 필요하면 `Tools > 347 > Toggle Numeric HP`
- HP 0에서 **편지를 태우면 부활**합니다. 태운 편지는 트루 엔딩 카운트에서 빠집니다

## 3. 붕괴선

항상 옵니다. 도하보다 느리지만 실수를 기억합니다 ([CollapseLine](../Scripts/CollapseLine.cs)).

| 값 | 숫자 |
|----|------|
| 시작 간격 | `45 m` |
| 속도 | 플레이어 현재 속도 `× 0.96` |
| 피격 페널티 | `-12 m` |
| 반격 보상 | `+6 m` |
| 경고 간격 | `15 m` (화면 탈색 + 무전 깨짐) |
| 사망 간격 | `0.5 m` → `DeathCause.Collapsed` |

속도가 플레이어에 비례하므로 **빨리 달려도 도망칠 수 없고, 안 맞으면 잡히지 않습니다.**

|----|------|

| 유휴 간격 | `34 m` |

## 5. 수집물 8종

이름으로 종류가 정해집니다 ([Pickup](../Scripts/Pickup.cs) 의 `KindFromName`).

| 종류 | 효과 |
|------|------|
| 배달 코인 | 점수 `+10 × 콤보` |
| 회수 태그 | 콤보 `+0.1`, **드론 추적 정확도 상승** |
| 부스터 셀 | 아이템 슬롯 · `4초` 속도 `+40%`, 붕괴선 `+30 m` |
| 실드 | 아이템 슬롯 · `8초` 1회 피격 무효 |
| 역스캔 | 아이템 슬롯 · `6초` 드론 조준 교란 |
| 응급 테이프 | 즉시 HP `+1`. HP가 낮을 때만 스폰 확률이 오릅니다 |
| 데크 조각 | 영구 통화. 재시작해도 남습니다 |
| 붕어의 편지 | 구역당 1개, 희귀. `5`개 = 트루 엔딩. HP 0에서 태우면 부활 |

## 6. 아이템 슬롯

**1칸, 덮어쓰기** ([ItemSlot](../Scripts/ItemSlot.cs)). 새로 주우면 들고 있던 게 사라집니다. 발동은 `Space` / `LeftShift` / 화면 탭.

## 7. 점수와 콤보

[GameManager](../Scripts/GameManager.cs)

```
점수 = 주행 거리(m) + 보너스
보너스 += 획득 점수 × 콤보
콤보  = 1 + 0.1 × 태그 수  (최대 5)
```

- 위험 보너스 `30/s` — 붕괴선 `20 m` 이내에서 달리는 동안
- 그라인드 보너스 `25/s`
- 피격하면 콤보가 **절반**으로 떨어집니다. 하지만 드론이 보는 태그 총량은 줄지 않습니다 — **점수는 잃고 위험은 남습니다**

## 8. 스폰 디렉터

긴장도를 재서 난이도를 흔듭니다 ([SpawnDirector](../Scripts/SpawnDirector.cs)). 관측창은 최근 `30 m`.

`tension` = HP 부족 + 붕괴선 근접 + 최근 피격 수

| tension | 결과 |
|---------|------|
| 낮음 | 장애물 밀도 상승, 회복 아이템 억제 |
| 높음 | 장애물 밀도 하강, 응급 테이프 확률 상승, **안전 차선 1개 보장** |

코스는 `Seed` 로 결정론적입니다. 같은 시드 = 같은 길.

## 9. 수거자 (보스)

4단계 사이클을 3페이즈 반복합니다 ([KingFight](../Scripts/KingFight.cs)).

```
Aim(0.6s) → Throw(0.5s) → CounterWindow(1.4s) → Recover(≥0.25s)
```

| 값 | 숫자 |
|----|------|
| 페이즈당 HP | `3` (총 `9`) |
| 경직 | `0.8초`, 이때 `30 m` 접근 |
| 아레나 속도 | `14 m/s` 고정 |
| 기본 거리 | `74 m`, 진폭 `±14 m` |
| 텔레그래프 하한 | `0.45초` |

투사체 4종: 컨테이너 파편(즉사), 회수망(포박), 태그 런처(HP 1), 레일 낙하(광역).
반격은 **자동**입니다. 열린 차선으로 들어가 있으면 됩니다 — 버튼이 하나 더 늘지 않습니다.
페이즈가 바뀔 때마다 회복 아이템 하나가 확정 드롭됩니다.

**단독 검증**: `F2` 또는 `Tools > 347 > Play King Arena`. 직선만 깔리고 장애물이 꺼지므로 보스 규칙만 남습니다. `F3` 로 러너 복귀.

## 10. 5구역

거리 기반입니다. 구역당 `1600 m`, 경계에서 `220 m` 블렌드 ([Zone](../Scripts/Zone.cs), [ZoneDirector](../Scripts/ZoneDirector.cs)).

| # | 구역 | 팔레트 | FX | 해금 |
|---|------|--------|----|------|
| 1 | 상가 골목 | 따뜻한 형광 | 전단지 | — |
| 2 | 고가도로 | 회청색 콘크리트 | 콘크리트 먼지 | 그라인드 |
| 3 | 침수 지하상가 | 녹청 + 짙은 안개 | 물안개 | 어둠 |
| 4 | 주거 타워 | 먼지 섞인 백색광 | 유리 파편 | 벽 주행 |
| 5 | 집하장 | 주황 나트륨등 + 적색 | 나트륨 티끌 | 역주행 |

구역마다 도로 타일 후보가 다릅니다 (`ZoneDirector.AllowsTile`). 구역에 들어가면 배너가 뜨고 무전 비트가 발동합니다.

## 11. 회차와 플래그

| PlayerPrefs 키 | 뜻 |
|----------------|-----|
| `r347_run_count` | 누적 사망 = 회차 |
| `r347_best_score` | 최고 점수 |
| `r347_deck_pieces` | 데크 조각 |

세션 플래그와 영구 플래그는 [FlagStore](../Scripts/FlagStore.cs) 가 나눠 관리합니다. 초기화는 `Tools > 347 > Reset Save Data`.

사망 화면은 `GAME OVER` 가 아니라 **회수 로그**입니다.

```
「A-0347 회수. 구역 2 · 고가도로, 거리 1,840 m. 기록 보관.」
회차 12 · 점수 1,840 · 최고 3,102 · 태그 8
```

## 12. 스토리 엔진

[StoryEngine](../Scripts/StoryEngine.cs) 이 트리거를 받아 채널 우선순위대로 재생합니다.

- 트리거: `OnDistance`, `OnZoneEnter`, `OnPickup`, `OnHit`, `OnDeath`, `OnBossPhase`, `OnRunCount`
- 채널 우선순위: `Control` > `Radio` > `AmbientVoice`. 낮은 채널은 밀립니다
- `once` / `repeatable`, `runs` 범위 조건, 발동 시 플래그 세팅 지원
- 데이터는 [events.json](../Resources/Story/events.json), 코드는 [StoryScript](../Scripts/StoryScript.cs)

## 13. 경제 · 성장 · 수집

상세 숫자는 [Economy.md](Economy.md). 구현 요약:
