# Coast Run — Style Bible (게임 표준)

> **Canonical reference:** `Assets/_Guide/Reference/style_reference.mp4`  
> 원본: Downloads `이런_느낌의_d_게임을_커서_요청해줘 (1).mp4`  
> 키프레임: `style_frame_1.jpg` ~ `style_frame_5.jpg`  
> 해상도: **720×1280 세로** · ~20초 · 24fps

이 영상이 **시각·카메라·월드 레이아웃의 정답**이다. 에셋·카메라·URP 결정은 여기와 어긋나면 틀린 것이다.

---

## 1. 한 장으로 읽는 구도

```
┌─────────────────────────┐
│     거대한 여름 구름      │  ← 화면 상단 35~45% 가 하늘
│   (페인터리 적란운)       │
├──────────┬──────────────┤
│ 전신주·전선 │              │
│ 언덕 마을   │   푸른 바다  │  ← 왼쪽=마을 / 오른쪽=바다
│ 보행 NPC   │   파도·거품  │
│            │   방파제     │
├──────────┴──────────────┤
│     ░ 해안 산책로 ░       │  ← 넓은 보도 / 석재 또는 아스팔트
│         🎒 소녀          │  ← 화면 **하단 1/3**, 약간 우측 또는 중앙
│        🛹 보드           │
└─────────────────────────┘
```

- **3인칭 백뷰**, 카메라가 **낮고** 살짝 **위를 본다** → 하늘·구름이 압도적.
- 소실점이 전방으로 열려 **속도·개방감**.
- HUD는 영상처럼 **거의 없음** (플레이 중 미니멀).

## 2. 주인공 (Lock)

| 항목 | 표준 |
|------|------|
| 체형 | 십대 소녀, 등신감 있는 카툰 비율 |
| 머리 | 짧은 브라운 / 또는 하이 포니 — **바람에 흩김** 필수 |
| 상의 | 머스타드 또는 블루 셔츠 (반팔·소매 걷음) |
| 하의 | 데님/블루 숏팬츠 |
| 가방 | **올리브/카키 대형 배낭** (여행·청량 시그니처) |
| 신발 | 틸/청록 + 화이트 스니커즈 |
| 보드 | 클래식 데크, **오렌지 휠** |
| 포즈 | 크루징 스탠스, 살짝 전경 기울임 |

애니메이션 우선순위: **Hair / Backpack strap / Shirt** 윈드 → 그다음 발·보드.

## 3. 월드 레이아웃 (Map 규칙)

| 측 | 콘텐츠 | 게임플레이 |
|----|--------|------------|
| **중앙** | 넓은 산책로 (보도블록 또는 노란 중앙선 도로) | 3레인 이동 |
| **왼쪽** | 해안 마을 — 상점, 발코니, **전신주·전선**, 가로등, 카페, 보행 NPC | 장애물·분위기 |
| **오른쪽** | 낮은 방파제 → 모래 → **청록 바다 + 흰 파도** | 낙하 위험(옵션), 뷰 |
| **원경** | 만곡 해안, 희미한 스카이라인, 언덕 | 패럴랙스 / 저폴리 |
| **하늘** | 진한 파랑 + **거대한 여름 구름** | 스카이박스 최우선 에셋 |

타일 세트 네이밍 예: `Tile_Promenade`, `Tile_TownL`, `Tile_SeaWallR`, `Tile_CurveSoft`.

## 4. 카메라 표준 (영상 = 정답)

| 파라미터 | 목표 값 (출발점) | 이유 |
|----------|------------------|------|
| 높이 | 캐릭터 허리~가슴 아래 | 낮은 앵글 |
| 거리 | ~2~3 m 뒤 (보드 기준) | 캐릭터가 작지 않게, 하늘은 크게 |
| Pitch | 살짝 위 (+5°~12°) | 구름 노출 |
| FOV | 55~70 (속도에 따라) | 개방감 |
| 캐릭터 화면 위치 | **하단 25~35%** | 영상과 동일 |
| 좌우 | 중앙~약 우측 | 왼쪽 마을 / 오른쪽 바다 균형 |

속도↑ → FOV↑, 미세 카메라 밥, 바람 VFX.  
템플런식 “머리 크게 클로즈업”은 **금지**.

---

## 5. 렌더 / 라이팅 표준

- **셀 셰이딩:** 2~3단 램프, 캐릭터·전경 오브젝트 **잉크 아웃라인**
- **태양광:** 강렬한 Directional, **날카로운 그림자** (소프트 섀도 과다 금지)
- **그림자 색:** 순검정이 아니라 **푸른기 도는 쿨 섀도**
- **채도:** 하늘·바다·구름 하이 채도 / 지상은 따뜻한 베이지·크림
- **대기:** 원경만 아주 약한 블루 헤이즈 (과한 Exponential fog 금지)
- **하이라이트:** 보도·파도 거품에 약한 스파클/블룸

모바일: Outline은 **캐릭터+보드만**. 전선은 텍스처 또는 단순 라인 메쉬.

---

## 6. 사운드·연출 톤

- BGM: 밝은 어쿠스틱 / 썸머 앰비언트
- SFX: 보드 휠, 바람, 파도 (거리감)
- 실패: 무겁지 않은 SoftHit (넘어짐 짧게 → 재가속)

---

## 7. 에셋 발주 체크리스트 (P0)

1. 소녀 리깅 + 배낭 + 보드 (아웃라인용 메시 포함)
2. 산책로 타일 30 m × 폭 ~8–10 m
3. 왼쪽 상점/전신주 세트
4. 오른쪽 방파제 + 바다 플레인(파도 셰이더)
5. 여름 구름 스카이 / 큐브맵
6. 보행 NPC 2~3종 (저폴리, 루프 워크)

## 8. 개발 시 검증 방법

Play Mode 스크린샷을 `style_frame_*.jpg`와 나란히 놓고 확인:

1. 하늘이 화면의 ⅓ 이상인가?
2. 왼쪽=마을, 오른쪽=바다인가?
3. 소녀가 하단 ⅓에 있는가?
4. 그림자가 날카롭고 파란기인가?
5. 전신주·전선이 보이는가?

하나라도 NO면 카메라/라이트/타일부터 고친다.
