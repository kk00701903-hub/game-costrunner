## Export rules

- **Blender FBX:** Forward -Z, Up Y, Apply Transform, low poly mobile
- **Photoshop:** sRGB PNG, sky 720×1280, tiles 1024–2048
- **Illustrator:** PNG export for UI icons

## StyleBible verify (every asset)

1. Sky ≥⅓ screen
2. Town left / sea right
3. Girl in bottom ⅓
4. Sharp cool shadows
5. Utility poles + wires visible
